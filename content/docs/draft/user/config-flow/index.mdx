## วิธีเข้าสู่หน้าเมนู

<Steps>
  <Step>
    เข้าสู่เมนู <b>หน้าแรก (Portal)</b>
  </Step>

  <Step>
    คลิกเข้าสู่เมนูระบบ <b>Draft</b>

    ![](/media/39042cb4-3a4b-4675-8664-66549226e61a.png)
  </Step>

  <Step>
    คลิกเลือกแท็บด์ <b>ตั้งค่าการตรวจสอบ</b> ที่แถบเมนูด้านบน

    ![](/media/776792bf-e20d-43ba-af1b-cbc317e0d831.png)
  </Step>
</Steps>

## องค์ประกอบภายในหน้าเมนู

    <Callout type="info">
            ต้องทำการเพิ่มรูปแบบการตรวจสอบของท่านก่อนถึงจะแสดงหน้าตัวอย่าง ดังรูป
    </Callout>

ภายในหน้าเมนูประกอบด้วยส่วนต่าง ๆ ดังนี้

![](/media/5f2f4a8a-d43c-447b-90a9-5a1d9068821c.png)

1. ช่องแสดงรูปแบบการตรวจสอบของท่าน
2. ช่องสำหรับ เพิ่มรูปแบบใหม่ และ แก้ไขรูปแบบ
3. ปุ่ม `สร้างรูปแบบ`
