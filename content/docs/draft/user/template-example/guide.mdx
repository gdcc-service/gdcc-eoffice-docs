## ตัวอย่างเอกสาร

ผู้ใช้งานสามารถดาวน์โหลดไฟล์ตัวอย่างหนังสือหรือแบบฟอร์มสกุลไฟล์ .doc หรือ .docx ลงไปในอุปกรณ์ของท่านเพื่อใช้ในการร่างหนังสือหรือกรอกแบบฟอร์มจากโปรแกรม Microsoft word หลังจากนั้น
save as pdf เพื่ออัปโหลดเข้ามาในระบบโดยมีวิธีการดังนี้

<Steps>
  <Step>
    เข้าสู่หน้า [แท็บด์ตัวอย่างเอกสาร](/docs/draft/user/template-example) ในเมนูระบบ Draft
  </Step>

  <Step>
    คลิกเข้าที่แท็บด์ “ตัวอย่างเอกสาร”

    ![](/media/0eb1d4aa-eebe-478c-a821-37149639936c.png)
  </Step>

  <Step>
    คลิกดาวน์โหลดจากไอคอนลูกศร ดังรูป

    <Callout type="info">
      กรณีที่หนังสือหรือแบบฟอร์มแสดงข้อความไม่พบตัวอย่าง หมายถึง ไฟล์ตัวอย่างยังไม่ถูกอัปโหลดมาจัดเก็บในระบบ ซึ่งผู้ที่มีสิทธิ์อัปโหลดไฟล์ตัวอย่างจะเป็นเจ้าหน้าที่ที่มีสิทธิ์ Admin ของระบบร่างเอกสาร (Draft)
    </Callout>

    ![](/media/c75dcd9b-b013-49b0-8e4d-85f6ba6de8c3.png)
  </Step>

  <Step>
    หลังจากนั้นไฟล์เอกสารจะถูกดาวน์โหลดและถูกจัดเก็บในอุปกรณ์ของท่าน

    ท่านสามารถดำเนินการร่างและกรอกข้อมูลให้เรียบร้อยแล้วบันทึกไฟล์เป็นสกุล .pdfหากเอกสารต้องดำเนินการในระบบให้ใช้วิธีการ “อัปโหลดเอกสารร่าง” หรือ “อัปโหลดเอกสารเพื่อออกเลข”
    เพื่อดำเนินการต่อจนเสร็จสิ้นกระบวนการของเอกสารนั้นๆ

    ![](/media/fa07a55f-347f-479a-91c6-705b9fe534fa.png)
  </Step>
</Steps>

## ขออนุญาตให้เห็นแฟ้มไฟล์ตลอดเส้นทาง

การติ๊ก “ขออนุญาตให้เห็นแฟ้มไฟล์ตลอดเส้นทาง” จะส่งผลให้เอกสารเมื่อออกเลขเสร็จสิ้นแล้วเมื่อหนังสือถูกส่งต่อไปตามส่วนงาน ผู้ใช้งานที่มีสิทธิ์ในแฟ้มทะเบียนของส่วนงานตามเส้นทางเดินเอกสารของ
หนังสือเรื่องนี้จะสามารถเปิดแฟ้มไฟล์เพื่อดูเอกสารที่ถูกอัปโหลดทั้งหมดของทุกส่วนงาน

<u>**ยกตัวอย่าง**</u> หนังสือออกเลขที่กลุ่มงาน A เมื่อส่งต่อหนังสือในระบบสารบรรณไปให้กลุ่ม B C และ D กลุ่มงานทั้งหมดจะเห็นไฟล์เอกสารที่ถูกอัปโหลดไว้ในแฟ้มไฟล์ของแต่ละส่วนงานที่อยู่ในทางเดินเอกสารของ
หนังสือเรื่องนี้

<Steps>
  <Step>
    ในขั้นตอนการออกเลขติ๊กใน checkbox “ขออนุญาตให้เห็นแฟ้มไฟล์ตลอดเส้นทาง”

    ![](/media/4765b13b-f809-40cc-9a8b-096b5ee17118.png)
  </Step>

  <Step>
    หลังจากกรอกข้อมูลสำหรับการออกเลขเรียบร้อยแล้วให้คลิกปุ่ม `ส่งออกเลข`

    ![](/media/d4c274f5-0664-4f55-964f-490dfbdd4cba.png)
  </Step>
</Steps>
