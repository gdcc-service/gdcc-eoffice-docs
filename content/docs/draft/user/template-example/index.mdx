## วิธีเข้าสู่หน้าเมนู

<Steps>
  <Step>
    เข้าสู่เมนู <b>หน้าแรก (Portal)</b>
  </Step>

  <Step>
    คลิกเข้าสู่เมนูระบบ <b>Draft</b>
  </Step>

  <Step>
    คลิกเลือกแท็บด์ <b>ตัวอย่างเอกสาร</b> ที่แถบเมนูด้านบน
  </Step>
</Steps>

***
