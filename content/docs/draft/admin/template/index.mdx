## วิธีเข้าสู่หน้าเมนู

<Steps>
  <Step>
    เข้าสู่เมนู <b>หน้าแรก (Portal)</b>
  </Step>

  <Step>
    คลิกเข้าสู่เมนูระบบ <b>Draft</b>

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/04/aura-markdown-new-doc-image-system-20260304-165643-1nxp8u.png)
  </Step>

  <Step>
    เปลี่ยนสิทธิ์การใช้งานจาก <b>User</b> เป็น <b>Admin</b> ที่แถบเมนูด้านขวาบน

    <Callout>
      กรณีไม่ปรากฏปุ่มสลับสิทธิ์ แสดงว่าผู้ใช้รายดังกล่าว ไม่มีสิทธิ์การใช้งานในบทบาท Admin ภายในเมนูระบบ draft
    </Callout>

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/04/aura-markdown-new-doc-image-system-20260304-142227-17x1ic.png)
  </Step>
</Steps>
