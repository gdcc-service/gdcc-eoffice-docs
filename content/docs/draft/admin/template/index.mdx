## วิธีเข้าสู่หน้าเมนู

<Steps>
  <Step>
    เข้าสู่เมนู <b>หน้าแรก (Portal)</b>
  </Step>

  <Step>
    คลิกเข้าสู่เมนูระบบ <b>Draft</b>

    ![](/media/c561e682-ee94-4a11-9148-2a5196a5dd84.png)
  </Step>

  <Step>
    เปลี่ยนสิทธิ์การใช้งานจาก <b>User</b> เป็น <b>Admin</b> ที่แถบเมนูด้านขวาบน

    <Callout>
      กรณีไม่ปรากฏปุ่มสลับสิทธิ์ แสดงว่าผู้ใช้รายดังกล่าว ไม่มีสิทธิ์การใช้งานในบทบาท Admin ภายในเมนูระบบ draft
    </Callout>

    ![](/media/2ec50419-571d-4e7b-b82b-fc4942e1150b.png)
  </Step>
</Steps>

***

## องค์ประกอบภายในหน้าเมนู

ภายในหน้าเมนูประกอบด้วยส่วนต่าง ๆ ดังนี้

![](/media/840be65c-528a-4783-b1c8-f14e29d6ceb5.png)

1. ช่องค้นหาประเภทเอกสาร
2. ช่องแสดงประเภทเอกสาร
3. ปุ่ม `+ เพิ่มประเภท`
