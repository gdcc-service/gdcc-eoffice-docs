ใช้สำหรับการติดประกาศที่เป็นรูปภาพในระบบ หรือ ใช้ในการแนบลิงก์ในรูปภาพเพื่อให้เข้าถึงเว็บไซต์ต่างๆ โดยผ่านแบนเนอร์ ส่วนประกอบของหน้า แบนเนอร์ มีดังนี้

## วิธีเข้าสู่หน้าเมนู แบนเนอร์

<Steps>
  <Step>
    เข้าสู่เมนู <b>หน้าแรก (Portal)</b>
  </Step>

  <Step>
    คลิกเข้าสู่เมนูระบบ <b>In-tray</b>

    ![](/media/8c286d87-bfe8-4497-852c-daf8daaddc19.png)
  </Step>

  <Step>
    เปลี่ยนสิทธิ์การใช้งานจาก <b>User</b> เป็น <b>Admin</b> ที่แถบเมนูด้านขวาบน

    <Callout>
      กรณีไม่ปรากฏปุ่มสลับสิทธิ์ แสดงว่าผู้ใช้รายดังกล่าว ไม่มีสิทธิ์การใช้งานในบทบาท Admin ภายในเมนูระบบ In-tray
    </Callout>

    ![](/media/2ec50419-571d-4e7b-b82b-fc4942e1150b.png)
  </Step>
</Steps>

***
