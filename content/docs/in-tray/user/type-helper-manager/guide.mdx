## การกำหนดตัวช่วยพิมพ์

    <Steps>
      <Step>
        เข้าสู่หน้า [แท็บด์กำหนดตัวช่วยพิมพ์](/docs/in-tray/user/type-helper-manager) ในเมนูระบบ In-tray
      </Step>

      <Step>
        ดำเนินการพิมพ์ข้อความ คำเกษียน/ความเห็น/ข้อสั่งการ ในช่องดังกล่าว และคลิกปุ่ม `+ เพิ่ม`
      </Step>

      <Step>
        หลังจากเพิ่มตัวช่วยพิมพ์เรียบร้อยแล้ว คลิกปุ่ม `บันทึก`
      </Step>
    </Steps>

### วิธีใช้งานตัวช่วยพิมพ์

สามารถใช้งานได้ 2 วิธีดังนี้

#### เลือกข้อความตัวช่วยพิมพ์

กรณีที่ไม่ได้ “+ เพิ่มกล่องข้อความในเอกสาร” หากคลิกเลือกตัวช่วยพิมพ์แล้วข้อความจะแสดงในช่อง คำเกษียน/ความเห็น/ข้อสั่งการ

กรณีที่ต้องการกล่องข้อความสามารถ “+ เพิ่มกล่องข้อความในเอกสาร” แล้ว หากคลิกเลือกตัวช่วยพิมพ์แล้วข้อความจะแสดงในกล่องข้อความล่าสุดที่เพิ่มเข้ามา

#### คัดลอกข้อความตัวช่วยพิมพ์

    <Steps>
      <Step>
        คลิกปุ่ม `คัดลอก` 
      </Step>

      <Step>
        จากนั้นนำไปวางในช่อง คำเกษียน/ความเห็น/ข้อสั่งการ ที่เลือกหรือที่เพิ่มขึ้นมา
      </Step>
    </Steps>
