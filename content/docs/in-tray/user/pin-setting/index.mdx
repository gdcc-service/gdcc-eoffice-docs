## วิธีเข้าสู่หน้าเมนู

<Steps>
  <Step>
    เข้าสู่เมนู <b>หน้าแรก (Portal)</b>
  </Step>

  <Step>
    คลิกเข้าสู่เมนูระบบ <b>In-tray</b>

    ![](https://r2-eoffice-docs.zire.dev/uploads/markdown/2026/03/04/aura-markdown-new-doc-image-system-20260304-151114-1576iw.png)
  </Step>

  <Step>
    คลิกเลือกแท็บด์ <b>เพิ่มเติม</b> หลังจากนั้นคลิกเลือก <b>ตั้งค่า Pin</b> ที่แถบเมนูด้านบน

    ![](https://r2-eoffice-docs.zire.dev/uploads/markdown/2026/03/04/aura-markdown-new-doc-image-system-20260304-160819-3av5z5.png)
  </Step>
</Steps>
