  </Step>

  <Step>
    คลิกเข้าสู่เมนูระบบ <b>In-tray</b>

## องค์ประกอบภายในหน้าเมนู

ภายในหน้าเมนูประกอบด้วยส่วนต่าง ๆ ดังนี้

![](/media/1e4286f6-fbab-4cac-8d57-3178e93b5682.png)

1. ช่องสำหรับติ๊กให้เป็นผู้กรองงานหลัก
2. ช่องแสดงรายชื่อผู้กรองงาน
3. ปุ่มเพิ่มผู้กรองงาน
4. ปุ่มสำหรับบันทึกและยกเลิก
