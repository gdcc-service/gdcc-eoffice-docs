ใช้จัดการข้อมูลหลักขององค์กร — โครงสร้างหน่วยงาน ตำแหน่ง ประเภทบุคลากร และระดับ — เพื่อให้การเพิ่มผู้ใช้งานและรายงานอ้างอิงข้อมูลที่ถูกต้อง

![](/media/10a37a56-e915-4d4f-b133-7e0984d082ef.png)

<Callout type="info">
  การแก้ไขข้อมูลหลักมีผลต่อทั้งองค์กร โดยทั่วไป **แอดมินหลัก** เป็นผู้ดูแลหลัก หากท่านเป็น **แอดมินรอง** และได้รับสิทธิ์เข้าเมนูนี้ ให้ดำเนินการภายในขอบเขตที่องค์กรกำหนด
</Callout>

## วิธีเข้าสู่หน้าเมนู

<Steps>
  <Step>
    เข้าสู่เมนู **หน้าแรก (Portal)**
  </Step>

  <Step>
    คลิกเข้าสู่เมนูระบบ **Admin Tools**

    ![](/media/ecb747f9-263d-4f72-8336-9c4f4abd8802.png)
  </Step>

  <Step>
    คลิกเมนู **ข้อมูลหลักองค์กร** ที่แถบเมนูด้านบน

    ![](/media/d15929da-0111-4075-9401-faa70db599c5.png)
  </Step>
</Steps>

***

## โครงสร้างองค์กร

| การ์ด | รายละเอียด |
| --- | --- |
| **โครงสร้างระดับ 1** | หน่วยงานระดับบนสุด |
| **โครงสร้างระดับ 2** | หน่วยงานระดับกลาง |
| **โครงสร้างระดับ 3** | หน่วยงานระดับล่างที่ผู้ใช้งานสังกัด — สำคัญต่อขอบเขต **แอดมินรอง** |

คลิกการ์ดเพื่อเปิดรายการ ค้นหา เพิ่ม แก้ไข หรือกำหนดสถานะใช้งาน — ดู [รายการโครงสร้างองค์กร](/docs/admin-tools/primary-admin/masterdata/listorg)

---

## ข้อมูลบุคลากร

| การ์ด | รายละเอียด |
| --- | --- |
| **ตำแหน่ง** | รายการตำแหน่งงาน |
| **ประเภทบุคลากร** | ประเภทการจ้างหรือสถานะบุคลากร |
| **ระดับ** | ระดับตำแหน่งหรือระดับบุคลากร |

แต่ละการ์ดแสดงจำนวนรายการ (เช่น **มี 45 รายการ**) และเปิดหน้ารายการเพื่อจัดการข้อมูลแบบเดียวกับโครงสร้างองค์กร
