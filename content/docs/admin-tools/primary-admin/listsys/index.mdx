ใช้กำหนดสิทธิ์การเข้าถึงระบบย่อยใน e-Office จัดลำดับการแสดงผล และตั้งค่าการแสดงผลของแต่ละระบบ

![](/media/fea61e89-fb12-452f-b46e-3eafb05c4f23.png)

<Callout type="info">
  การตั้งค่าในเมนูนี้มีผลทั้งองค์กร **แอดมินรอง** ที่ได้รับสิทธิ์เข้าเมนูจัดการระบบจะเห็นและดำเนินการได้ตามขอบเขตที่องค์กรกำหนด — หากท่านไม่เห็นเมนูนี้ ให้ติดต่อ **แอดมินหลัก**
</Callout>

## วิธีเข้าสู่หน้าเมนู

<Steps>
  <Step>
    เข้าสู่เมนู **หน้าแรก (Portal)**
  </Step>

  <Step>
    คลิกเข้าสู่เมนูระบบ **Admin Tools**

    ![](/media/ecb747f9-263d-4f72-8336-9c4f4abd8802.png)
  </Step>

  <Step>
    คลิกเมนู **จัดการระบบ** ที่แถบเมนูด้านบน

    ![](/media/d108848f-6c23-492a-b678-b80d8beaebc5.png)
  </Step>
</Steps>

***

## การ์ดระบบย่อย

แต่ละการ์ดแสดงชื่อระบบ (เช่น Portal, Admin Tools, draft, In-tray, ระบบสารบรรณ) จำนวนผู้ที่ได้รับสิทธิ์ (เช่น **มี 93 รายการ**) และปุ่มดำเนินการ

| องค์ประกอบ | การใช้งาน |
| --- | --- |
| ไอคอนเฟือง | เปิดตั้งค่าระบบและจัดการสิทธิ์ผู้ใช้งานรายระบบ — ดู [รายการผู้ใช้งานระบบ](/docs/admin-tools/primary-admin/listsys/listusersys) |
| ไอคอนลิงก์ภายนอก | เปิดหน้าตั้งค่าการแสดงผล — ดู [แก้ไขไอคอนและรูปภาพ](/docs/admin-tools/primary-admin/listsys/editiconimg) |
| **สิทธิ์การใช้งานตั้งต้น** | สลับเปิด/ปิดสิทธิ์ตั้งต้นให้ผู้ใช้งานใหม่ (ถ้าระบบรองรับ) |

<Callout type="warn">
  ระบบ **Admin Tools** ไม่สามารถเปิด **สิทธิ์การใช้งานตั้งต้น** ได้ อย่าเปลี่ยนสวิตช์สิทธิ์ตั้งต้นของระบบอื่นโดยไม่ทำความเข้าใจผลกระทบต่อผู้ใช้งานทั้งองค์กร
</Callout>

## จัดการลำดับการแสดงผล
