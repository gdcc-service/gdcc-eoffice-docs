  <Step>

## องค์ประกอบภายในหน้าเมนู

![](/media/fea61e89-fb12-452f-b46e-3eafb05c4f23.png)

ภายในหน้าเมนูประกอบด้วยส่วนต่าง ๆ ดังนี้

1. เมนูกำหนดสิทธิ์ต่างๆ
2. ปุ่ม `ตั้งค่าการแสดงผลระบบ`
3. ปุ่ม `จัดการลำดับการแสดงผล`
