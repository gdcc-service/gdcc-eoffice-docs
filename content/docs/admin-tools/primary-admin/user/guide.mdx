<Callout type="info">
  **แอดมินรอง** ค้นหาและกรองผู้ใช้งานได้เฉพาะภายใน **โครงสร้างระดับที่ 3 ที่ตัวเองสังกัด**
</Callout>

## การค้นหาข้อมูลผู้ใช้งาน

<Steps>
  <Step>
    เข้าสู่ [หน้าจัดการผู้ใช้งาน](/docs/admin-tools/primary-admin/user) แล้วดูส่วน **ค้นหาข้อมูลผู้ใช้งาน** ด้านซ้าย

    ![](/media/f7e5cfaf-5246-43ac-abc6-f53708089dd6.png)
  </Step>

  <Step>
    ระบุเงื่อนไขในช่องที่ต้องการ เช่น **ชื่อ-สกุล** **Username** **อีเมล** หรือเลือก **โครงสร้างองค์กร** จากต้นไม้หน่วยงาน

    ![](/media/e38c1d77-50da-4716-854c-1f3545b03f47.png)
  </Step>

  <Step>
    คลิกปุ่ม `กรอง` เพื่อแสดงผล หรือ `ล้าง` เพื่อเริ่มค้นหาใหม่

    ![](/media/ff35babf-0009-4303-a6f6-5436e7ba7754.png)
  </Step>
</Steps>

---

## กรองตามสถานะการทำงาน

หากต้องการดูเฉพาะผู้ที่ยังทำงานอยู่หรือผู้ที่ออกจากงานแล้ว ให้เลือกสถานะ **ทำงาน** หรือ **ออกจากงาน** แทน **ทั้งหมด** แล้วคลิก `กรอง`

![](/media/e2a9d4ba-57e2-4123-b627-62c03e777191.png)
