ใช้สำหรับค้นหาข้อมูลผู้ใช้งานภายในระบบ และจัดการข้อมูลของผู้ใช้เช่น เพิ่มข้อมูลผู้ใช้งานใหม่เข้าระบบ เป็นต้น

## วิธีเข้าสู่หน้าเมนู

<Steps>
  <Step>
    เข้าสู่เมนู **หน้าแรก (Portal)**
  </Step>

  <Step>
    คลิกเข้าสู่เมนูระบบ **Admin Tools**

    ![](/media/ecb747f9-263d-4f72-8336-9c4f4abd8802.png)
  </Step>

  <Step>
    คลิกเลือกแท็บด์ **จัดการผู้ใช้งาน** ที่แถบเมนูด้านบน

    ![](/media/01ac0516-582a-47ee-bd39-f316410a6fe2.png)
  </Step>
</Steps>

***

## องค์ประกอบภายในหน้าเมนู

![](/media/bcc75065-dfda-4c2a-9700-8a532a8bb5ac.png)

ภายในหน้าเมนูประกอบด้วยส่วนต่าง ๆ ดังนี้

1. ช่องค้นหาข้อมูลผู้ใช้งาน
2. ส่วนแสดงรายการข้อมูลผู้ใช้งาน
3. ปุ่ม `นำเข้าไฟล์`
4. ปุ่ม `+ เพิ่ม`
