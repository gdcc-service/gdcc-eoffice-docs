ท่านใช้หน้านี้ค้นหาและจัดการข้อมูลผู้ใช้งานในองค์กร เพิ่มผู้ใช้งานใหม่ นำเข้าจากไฟล์ และเปิดหน้ารายละเอียดเพื่อแก้ไขข้อมูลหรือกำหนดสิทธิ์

![](/media/c6a1ad6a-b66f-4937-8d3d-eedf4f1998e4.png)

<Callout type="info">
  **แอดมินรอง** จะเห็นและจัดการผู้ใช้งานได้เฉพาะภายใน **โครงสร้างระดับที่ 3 ที่ตัวเองสังกัด** ช่องค้นหา ตัวกรองโครงสร้าง และรายการในตารางจะถูกจำกัดตามขอบเขตนี้
</Callout>

## ส่วนค้นหาและกรอง (ด้านซ้าย)

ช่อง **ค้นหาข้อมูลผู้ใช้งาน** ประกอบด้วย

- **รหัสพนักงาน**
- **ชื่อ-สกุล**
- **Username**
- **อีเมล**
- **สถานะ** — `ทั้งหมด` | `ทำงาน` | `ออกจากงาน`
- **โครงสร้างองค์กร** — เลือกจากต้นไม้โครงสร้างหน่วยงาน

ปุ่ม `ล้าง` ล้างเงื่อนไขการค้นหา ปุ่ม `กรอง` แสดงผลตามเงื่อนไข

รายละเอียดขั้นตอนการค้นหา ดูที่ [การใช้งาน จัดการผู้ใช้งาน](/docs/admin-tools/primary-admin/user/guide)

## รายการข้อมูลผู้ใช้งาน

ปุ่มด้านบนของตาราง

- `นำเข้าผู้ใช้จากไฟล์` — นำเข้าผู้ใช้งานหลายรายจากไฟล์
- `เพิ่มผู้ใช้` — เพิ่มผู้ใช้งานทีละราย ดู [เพิ่มข้อมูลผู้ใช้งาน](/docs/admin-tools/primary-admin/user/add)

คอลัมน์ในตาราง

| คอลัมน์ | รายละเอียด |
| --- | --- |
| **ชื่อ-สกุล** | อาจแสดงป้าย **แอดมินหลัก** ใต้ชื่อสำหรับผู้ดูแลระบบระดับองค์กร |
| **อีเมล** | ที่อยู่อีเมลในระบบ |
| **รหัสพนักงาน** | รหัสประจำตัวพนักงาน (ถ้ามี) |
| **โครงสร้างระดับที่ 2** | หน่วยงานระดับ 2 |
| **โครงสร้างระดับที่ 3** | หน่วยงานระดับ 3 ที่ผู้ใช้สังกัด |
| **สถานะ** | เช่น `ทำงาน` หรือ `ออกจากงาน` |

คลิกแถวผู้ใช้งานเพื่อเปิด [จัดการข้อมูลผู้ใช้งาน](/docs/admin-tools/primary-admin/user/detail)
