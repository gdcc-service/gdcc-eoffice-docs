title: เพิ่มข้อมูลผู้ใช้งาน
---

<Callout type="info">
  **แอดมินรอง** สามารถเพิ่มผู้ใช้งานได้เฉพาะเมื่อกำหนดสังกัดอยู่ใน **โครงสร้างระดับที่ 3 ที่ตัวเองสังกัด**
</Callout>

## ขั้นตอนเพิ่มข้อมูลผู้ใช้งานแบบรายท่าน

<Steps>
  <Step>
    เข้าสู่ [หน้าจัดการผู้ใช้งาน](/docs/admin-tools/primary-admin/user#วิธีเข้าสู่หน้าเมนู)
  </Step>

  <Step>
    คลิกปุ่ม `เพิ่มผู้ใช้`

    ![](/media/9f7c59c4-24c1-4e0a-a441-e8ac6150c97e.png)
  </Step>

  <Step>
    กรอกข้อมูลในหน้าเพิ่มผู้ใช้งาน โดยแบ่งเป็นส่วนหลักดังนี้

    ### ข้อมูลการเข้าสู่ระบบ

    ตั้ง **Username** และ **รหัสผ่าน** สำหรับ [เข้าสู่ระบบด้วย Username](/docs/auth/username)

    แนวทางตั้ง Username: ชื่อจริงภาษาอังกฤษ + `.` + อักษรสามตัวแรกของนามสกุล (เช่น สมชาย ใจดี → `somchai.jai`)

    เปิด `ตั้งค่าเปลี่ยนรหัส (เมื่อมีการ login ครั้งแรก)` หากต้องการบังคับเปลี่ยนรหัสผ่านเมื่อเข้าสู่ระบบครั้งแรก

    รหัสผ่านต้องมีความยาวอย่างน้อย 8 ตัวอักษร และประกอบด้วยตัวพิมพ์ใหญ่ ตัวพิมพ์เล็ก ตัวเลข และอักขระพิเศษ

    ![](/media/328ae9dc-8066-47b5-bfd3-8936fe76925d.png)

    ### ข้อมูลส่วนตัว

    ชื่อ-นามสกุล (ไทย/อังกฤษ) คำนำหน้า เพศ อีเมล ชื่อเล่น เบอร์โทรศัพท์ และรูปโปรไฟล์

    **อีเมล** ต้องไม่ซ้ำกับผู้ใช้งานรายอื่น (เวอร์ชัน 1.11.2 ปรับการตรวจสอบรูปแบบอีเมลให้เข้มงวดขึ้น)

    ![](/media/37c8063a-2edc-4140-bf1c-a3354361e023.png)

    ### ข้อมูลการเป็นพนักงานและสังกัดหน่วยงาน

    ระบุ **รหัสพนักงาน** **ตำแหน่ง** **ประเภทบุคลากร** **ระดับ** และ **โครงสร้างระดับที่ 1–3**

    ![](/media/a1017c6f-f293-4e40-9463-82e65d8321aa.png)
  </Step>

  <Step>
    คลิกปุ่ม `บันทึก` ระบบจะกลับไปหน้ารายการผู้ใช้งาน และแสดงผู้ใช้งานที่เพิ่มใหม่ในตาราง

    ![](/media/a69f8abc-b64b-47d5-82be-275e0b54abb6.png)
  </Step>
</Steps>
