เมนู **ออกรายงาน** ใช้สร้างไฟล์รายงานข้อมูลบุคลากรและสถิติการเข้าใช้งานระบบตามเงื่อนไขที่เลือก

![](/media/daf920c8-5ea3-4b99-8cc4-87fdc02f1bf2.png)

## วิธีเข้าสู่หน้าเมนู

<Steps>
  <Step>
    เข้าสู่เมนู **หน้าแรก (Portal)**
  </Step>

  <Step>
    คลิกเข้าสู่เมนูระบบ **Admin Tools**

    ![](/media/ecb747f9-263d-4f72-8336-9c4f4abd8802.png)
  </Step>

  <Step>
    คลิกเมนู **เพิ่มเติม** ที่แถบเมนูด้านบน แล้วเลือก **ออกรายงาน**

    ![](/media/86038cab-c2f8-4efb-bdab-4b128d838837.png)
  </Step>
</Steps>

***

## ประเภทรายงาน

| รายงาน | คำอธิบาย |
| --- | --- |
| **รายงานข้อมูลบุคลากร** | กรองตามหน่วยงาน ประเภทบุคลากร ระดับ ตำแหน่ง เพศ แล้วเลือกประเภทไฟล์ |
| **รายงานสถิติการเข้าใช้งานระบบ** | สรุปสถิติการเข้าใช้งานตามช่วงเวลาและเงื่อนไขที่ระบบกำหนด |

รายละเอียดขั้นตอน ดูที่ [รายงานผู้ใช้งานในระบบ](/docs/admin-tools/primary-admin/report/reportuser)

---

## องค์ประกอบร่วมในหน้าออกรายงาน

1. ช่องเลือกเงื่อนไข (หน่วยงาน ประเภทบุคลากร ระดับ ตำแหน่ง ฯลฯ)
2. **เลือกประเภทไฟล์การออกรายงาน** (เช่น `.xlsx` `.pdf` `.docx`) — ช่องนี้จำเป็นต้องเลือก
3. ปุ่ม `ล้าง` และ `ออกรายงาน`

<Callout type="info">
  หากไม่ระบุเงื่อนไขบางช่องและเลือกประเภทไฟล์แล้ว ระบบอาจออกรายงานข้อมูลบุคลากรทั้งหมดที่มีในระบบ (ตามกฎของรายงานนั้น)
</Callout>
