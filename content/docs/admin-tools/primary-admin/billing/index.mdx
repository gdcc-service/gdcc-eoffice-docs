เมนู **สรุปการใช้บริการ** ใช้ตรวจสอบรอบการสรุปการใช้บริการขององค์กร และดูรายชื่อผู้ใช้งานที่ถูกปิดใช้งาน

![](/media/ff4183f6-f1ec-42a6-8cf7-676ee9e7a2d3.png)

## วิธีเข้าสู่หน้าเมนู

<Steps>
  <Step>
    เข้าสู่เมนู **หน้าแรก (Portal)**
  </Step>

  <Step>
    คลิกเข้าสู่เมนูระบบ **Admin Tools**

    ![](/media/ecb747f9-263d-4f72-8336-9c4f4abd8802.png)
  </Step>

  <Step>
    คลิกเมนู **สรุปการใช้บริการ** ที่แถบเมนูด้านบน
  </Step>
</Steps>

---

## แท็บภายในหน้า

### รายงานสรุปการใช้บริการ

แสดงตารางรอบการสรุป โดยทั่วไปมีคอลัมน์ดังนี้

| คอลัมน์ | รายละเอียด |
| --- | --- |
| **รอบวันที่** | ช่วงวันที่ของรอบสรุป |
| **ผู้ตรวจสอบ** | ผู้ดูแลที่ตรวจสอบรอบนั้น |
| **วันที่ตรวจสอบ** | วันที่ดำเนินการตรวจสอบ |
| **สถานะ** | สถานะของรอบสรุป |

คลิกรายการในตารางเพื่อดูรายละเอียดรอบนั้น (หากระบบเปิดให้ดู)

### ผู้ใช้งานที่ถูกปิดใช้งาน

แสดงรายชื่อผู้ใช้งานที่ถูกปิดการใช้งาน หน้าต่างรายละเอียดเป็นแบบอ่านอย่างเดียว

- ปุ่ม `กู้คืน` อาจแสดงสำหรับนำผู้ใช้งานกลับมาใช้งานได้อีก (ขึ้นกับนโยบายองค์กรและสิทธิ์ของท่าน)

<Callout type="info">
  การสรุปการใช้บริการมักเป็นหน้าที่ของ **แอดมินหลัก** หรือผู้ที่ได้รับมอบหมาย หากท่านเป็น **แอดมินรอง** และไม่เห็นเมนูนี้ ให้ติดต่อแอดมินหลัก
</Callout>
