## คำอธิบายเมนู Admin Tools

![](/media/1c89cdc2-102d-49ac-bb95-c4d6ba5d46a5.png)

Admin Tools คือ เมนูสำหรับผู้ดูแลระบบ ใช้สำหรับจัดการข้อมูล ตั้งค่าระบบ และตรวจสอบการใช้งานของผู้ใช้งานในระบบ โดยผู้ที่สามารถเข้าถึงเมนูนี้จะต้องได้รับสิทธิ์ตามที่ระบบกำหนด

- จัดการข้อมูลผู้ใช้งาน เช่น เพิ่ม แก้ไข หรือนำเข้าข้อมูลผู้ใช้งาน
- จัดการสิทธิ์การใช้งาน กำหนดว่าผู้ใช้งานแต่ละรายสามารถเข้าถึงเมนูหรือฟังก์ชันใดได้บ้าง
- จัดการข้อมูลหน่วยงานและโครงสร้างองค์กร เช่น ส่วนงาน ตำแหน่ง หรือข้อมูลที่เกี่ยวข้อง
- ตรวจสอบและจัดการข้อมูลในระบบ เพื่อให้ข้อมูลมีความถูกต้องและเป็นปัจจุบัน
