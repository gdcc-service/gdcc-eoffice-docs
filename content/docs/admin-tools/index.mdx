## Admin Tools คืออะไร

![](/media/1c89cdc2-102d-49ac-bb95-c4d6ba5d46a5.png)

**Admin Tools** คือเมนูสำหรับผู้ดูแลระบบในแพลตฟอร์ม e-Office ใช้จัดการข้อมูลผู้ใช้งาน ตั้งค่าระบบ ข้อมูลหลักองค์กร ตรวจสอบการใช้งาน และออกรายงานที่เกี่ยวข้องกับการบริหารองค์กร

ความสามารถหลักที่ท่านจะพบใน Admin Tools ได้แก่

- จัดการข้อมูลผู้ใช้งาน เช่น เพิ่ม แก้ไข หรือนำเข้าข้อมูลผู้ใช้งาน
- จัดการสิทธิ์การใช้งาน กำหนดว่าผู้ใช้งานแต่ละรายสามารถเข้าถึงเมนูหรือฟังก์ชันใดได้บ้าง
- จัดการข้อมูลหน่วยงานและโครงสร้างองค์กร เช่น ส่วนงาน ตำแหน่ง หรือข้อมูลที่เกี่ยวข้อง
- ตรวจสอบและจัดการข้อมูลในระบบ เพื่อให้ข้อมูลมีความถูกต้องและเป็นปัจจุบัน

## สิทธิ์ผู้ดูแลระบบ: แอดมินหลัก และ แอดมินรอง

ระบบแยกสิทธิ์ผู้ดูแล Admin Tools เป็น 2 ระดับ ตามที่แสดงในเมนูจริง (เวอร์ชัน 1.11.0 ขึ้นไป)

| สิทธิ์ | ชื่อในระบบ | ขอบเขตการใช้งานโดยสรุป |
| --- | --- | --- |
| ผู้ดูแลระบบเต็มรูปแบบ | **แอดมินหลัก** | จัดการได้ทั้งองค์กร เทียบเท่าสิทธิ์ผู้ดูแลระบบเต็มรูปแบบในเวอร์ชันก่อนหน้า |
| ผู้ดูแลระบบจำกัดขอบเขต | **แอดมินรอง** | จัดการผู้ใช้งานได้ **เฉพาะภายในโครงสร้างระดับที่ 3 ที่ตัวเองสังกัด** และตามเมนูที่ได้รับมอบหมาย |

<Callout type="info">
  ในเมนู Admin Tools ปัจจุบันไม่มีคำว่า “Super Admin” อีกต่อไป ท่านจะเห็นคำว่า **แอดมินหลัก** และ **แอดมินรอง** แทน (เริ่มในเวอร์ชัน 1.11.0)
</Callout>

**แอดมินหลัก** สามารถใช้งานเมนูหลักทั้งหมด รวมถึง **จัดการแอดมินรอง** ภายใต้เมนู **เพิ่มเติม**

**แอดมินรอง** ใช้จัดการผู้ใช้งานในหน่วยงานของตนเองเท่านั้น ไม่ครอบคลุมทั้งองค์กร และไม่สามารถมอบหมายแอดมินรองให้หน่วยงานอื่นได้

## วิธีเข้าใช้งาน Admin Tools จาก Portal

<Steps>
  <Step>
    เข้าสู่เมนู **หน้าแรก (Portal)** ขององค์กร
  </Step>

  <Step>
    คลิกเข้าสู่เมนูระบบ **Admin Tools**

    ![](/media/ecb747f9-263d-4f72-8336-9c4f4abd8802.png)
  </Step>

  <Step>
    ระบบจะเปิดหน้า **หน้าหลัก** ของ Admin Tools ท่านสามารถเลือกเมนูจากแถบด้านบนตามสิทธิ์ของท่าน
  </Step>
</Steps>
