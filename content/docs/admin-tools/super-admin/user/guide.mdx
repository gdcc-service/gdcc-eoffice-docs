## การค้นหาข้อมูลผู้ใช้งาน

<Steps>
  <Step>
ใช้สำหรับค้นหาข้อมูลผู้ใช้งานทั้งหมดในระบบ สามารถค้นจาก รหัส,ชื่อ-สกุล,ID : Usernme,Email หรือ ค้นหาจากโครงสร้างได้

![](/media/f7e5cfaf-5246-43ac-abc6-f53708089dd6.png)
  </Step>
  <Step>
เลือกช่องที่ต้องการค้นหา ตัวอย่าง เช่น เลือกช่อง ชื่อ-สกุล

![](/media/e38c1d77-50da-4716-854c-1f3545b03f47.png)
  </Step>
  <Step>
จากนั้นคลิกที่ปุ่ม `กรอง` ระบบจะแสดงรายชื่อของผู้ใช้งานที่ต้องการค้นหาขึ้นมา <br />
ปุ่ม `กรอง` ใช้สำหรับค้นหา <br />
ปุ่ม `ล้าง` ใช้สำหรับล้างข้อมูลเพื่อค้นหารายชื่อใหม่

![](/media/ff35babf-0009-4303-a6f6-5436e7ba7754.png)
  </Step>
</Steps>

---

กรณีที่ต้องการค้นหารายชื่อผู้ใช้งานที่ออกจากระบบแล้ว หรือ ถูกปิดการใช้งาน สามารถเลือกในช่องสถานะที่ต้องการค้นหาปรับเป็น ทำงาน/ออกจากงาน ในช่องดังกล่าวได้

![](/media/e2a9d4ba-57e2-4123-b627-62c03e777191.png)
