## การค้นหาข้อมูลผู้ใช้งาน

<Steps>
  <Step>
ใช้สำหรับค้นหาข้อมูลผู้ใช้งานทั้งหมดในระบบ สามารถค้นจาก รหัส,ชื่อ-สกุล,ID : Usernme,Email หรือ ค้นหาจากโครงสร้างได้

![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/27/aura-markdown-new-doc-image-system-20260227-140757-lb9m84.png)
  </Step>
  <Step>
เลือกช่องที่ต้องการค้นหา ตัวอย่าง เช่น เลือกช่อง ชื่อ-สกุล

![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/27/aura-markdown-new-doc-image-system-20260227-140834-1iso7a.png)
  </Step>
  <Step>
จากนั้นคลิกที่ปุ่ม `กรอง` ระบบจะแสดงรายชื่อของผู้ใช้งานที่ต้องการค้นหาขึ้นมา <br />
ปุ่ม `กรอง` ใช้สำหรับค้นหา <br />
ปุ่ม `ล้าง` ใช้สำหรับล้างข้อมูลเพื่อค้นหารายชื่อใหม่

![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/27/aura-markdown-new-doc-image-system-20260227-140902-1nsh6u.png)
  </Step>
</Steps>

---

กรณีที่ต้องการค้นหารายชื่อผู้ใช้งานที่ออกจากระบบแล้ว หรือ ถูกปิดการใช้งาน สามารถเลือกในช่องสถานะที่ต้องการค้นหาปรับเป็น ทำงาน/ออกจากงาน ในช่องดังกล่าวได้

![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/27/aura-markdown-new-doc-image-system-20260227-140945-t05ubg.png)
