## ขั้นตอนเพิ่มข้อมูลผู้ใช้งานแบบรายท่าน

<Steps>
  <Step>
    เข้าสู่ [หน้าจัดการผู้ใช้งาน](/docs/admin-tools/super-admin/user#วิธีเข้าสู่หน้าจัดการผู้ใช้งาน)
  </Step>

  <Step>
    ในหน้าจัดการผู้ใช้งาน คลิกที่ปุ่ม `+ เพิ่ม`

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/27/aura-markdown-new-doc-image-system-20260227-142311-45htsj.png)
  </Step>

  <Step>
    ระบบจะแสดงหน้าให้เพิ่มข้อมูลผู้ใช้งาน ในหน้านี้ระบบจะแบ่งเป็น 3 ส่วนหลักๆ

    ### ส่วนที่ 1). ข้อมูลการเข้าสู่ระบบ

    ใช้สำหรับการตั้งค่า ชื่อบัญชีผู้ใช้งาน(Username) และ รหัสผ่าน ให้กับผู้ใช้ใหม่สำหรับ [เข้าสู่ระบบด้วย Username](/docs/auth/username)

    โดยในช่อง "ชื่อบัญชีผู้ใช้งาน" ให้ระบุ “ชื่อจริง” ตามด้วยจุด (.) และตามด้วย “อักษรสามตัวแรกของนามสกุล” เป็นภาษาอังกฤษ
    ตัวอย่างเช่น นายสมชาย ใจดี จะใช้ชื่อบัญชีผู้ใช้งานคือ somchai.jai

    ปุ่ม `ตั้งค่าเปลี่ยนรหัส(เมื่อมีการ login ครั้งแรก)` เมือเปิดใช้จะเป็นการบังคับให้ผู้ใช้งานตั้งรหัสผ่านใหม่เมื่อเข้าสู่ระบบครั้งแรก

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/27/aura-markdown-new-doc-image-system-20260227-154654-1f2e6u.png)

    ### ส่วนที่ 2). ข้อมูลส่วนตัว

    ใช้สำหรับการเพิ่มข้อมูลรายละเอียดส่วนตัวของผู้ใช้งานเข้าระบบ เช่น ชื่อ-นามสกุลและคำนำหน้าชื่อ ทั้งภาษาไทยและภาษาอังกฤษ, เพศ, E-mail, ชื่อเล่น, เบอร์โทรศัพท์, รูปโปรไฟล์

    โดย E-mail จะต้องไม่ซ่ำกับผู้ใช้งานรายอื่นๆในระบบ

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/27/aura-markdown-new-doc-image-system-20260227-153734-o7ria.png)

    ### ส่วนที่ 3). ข้อมูลการเป็นพนักงานและสังกัดหน่วยงาน

    ใช้สำหรับหรับเพิ่มข้อมูลการเป็นพนักงาน เช่น ตำแหน่ง, ประเภทบุคคลากร, ระดับ <br />
    สังกัดหน่วยงาน *(โครงสร้างระดับที่ 1, โครงสร้างระดับที่ 2, โครงสร้างระดับที่ 3)*

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/27/aura-markdown-new-doc-image-system-20260227-154459-7yclly.png)
  </Step>

  <Step>
    คลิกที่ปุ่ม `บันทึก` หลังจากนั้นระบบจะพากลับมายังหน้าจัดการผู้ใช้งาน ให้ทำการตรวจสอบในส่วนของ "รายการข้อมูลผู้ใช้งาน" จะแสดงรายชื่อของผู้ใช้งานที่มีการเพิ่มเข้าระบบ

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/05/aura-markdown-new-doc-image-system-20260305-141222-5wymhr.png)
  </Step>
</Steps>
