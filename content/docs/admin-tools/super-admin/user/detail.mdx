***

## จัดการข้อมูลผู้ใช้งาน

สำหรับหน้า "จัดการข้อมูลผู้ใช้งาน" ใช้สำหรับแก้ไขข้อมูลส่วนตัวของผู้ใช้งาน

<Steps>
  <Step>
    คลิกเลือกผู้ใช้งานที่ต้องการแก้ไข
  </Step>

  <Step>
    เลือกหัวข้อ "จัดการข้อมูลผู้ใช้งาน" คลิกปุ่ม `แก้ไข` ระบบจะแสดงหน้ารายละเอียดของผู้ใช้งาน
  </Step>

  <Step>
    หลังจากที่มีการแก้ไขข้อมูลเรียบร้อยแล้ว ให้เลื่อลงด้านล่างและคลิกปุ่ม `บันทึก`
  </Step>
</Steps>

***

## จัดการข้อมูลส่วนบุคคล

สำหรับหน้า "จัดการข้อมูลส่วนบุคคล" ใช้สำหรับการเพิ่มข้อมูลที่อยู่ของผู้ใช้งานและข้อมูลการติดต่อส่วนบุคคล

<Steps>
  <Step>
    คลิกเลือกผู้ใช้งานที่ต้องการแก้ไข
  </Step>

  <Step>
    เลือกหัวข้อ "จัดการข้อมูลส่วนบุคคล" คลิกปุ่ม `+ เพิ่มข้อมูลส่วนบุคคล` ระบบจะแสดงหน้ารายละเอียดของที่อยู่และข้อมูลการติดต่อ
  </Step>

  <Step>
    หลังจากที่มีการแก้ไขข้อมูลเรียบร้อยแล้ว ให้เลื่อลงด้านล่างและคลิกปุ่ม `บันทึก`
  </Step>
</Steps>

***

## จัดการสิทธิ์

สำหรับหน้า "จัดการสิทธิ์" ใช้สำหรับการเพิ่มเมนูในการใช้งานต่างๆ ให้แสดงขึ้มมาในหน้าของผู้ใช้งาน

<Steps>
  <Step>
    คลิกเลือกผู้ใช้งานที่ต้องการแก้ไข
  </Step>

  <Step>
    เลือกหัวข้อ "จัดการสิทธิ์"

    <Callout>
      เมื่อกำหนดสิทธิ์การใช้งานเมนูใดๆให้เป็น OFF ทั้งหมด User และ Admin <u>เมนูดังกล่าวจะไม่ปรากฏในระบบ</u>
    </Callout>

    <Callout type="warn">
      หากมีการปิดสิทธิืใช้งานเมนู Portal (ตั้งค่าเป็น OFF) ทั้งสิทธิ์ User และ Admin <u>ระบบจะไม่อนุญาตให้ผู้ใช้งานเข้าสู่ระบบ</u>
    </Callout>
  </Step>
