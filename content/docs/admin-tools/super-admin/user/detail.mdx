ในหน้า "จัดการข้อมูลผู้ใช้งาน" ใช้สำหรับแก้ไขข้อมูลของผู้ใช้งานและการกำหนดสิทธิ์ในการเข้าถึงเมนูภายในหน่วยงาน

***

## จัดการข้อมูลผู้ใช้งาน

สำหรับหน้า "จัดการข้อมูลผู้ใช้งาน" ใช้สำหรับแก้ไขข้อมูลส่วนตัวของผู้ใช้งาน

<Steps>
  <Step>
    คลิกเลือกผู้ใช้งานที่ต้องการแก้ไข

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/10/aura-markdown-new-doc-image-system-20260310-151250-rnkzsj.png)
  </Step>

  <Step>
    เลือกหัวข้อ "จัดการข้อมูลผู้ใช้งาน" คลิกปุ่ม `แก้ไข` ระบบจะแสดงหน้ารายละเอียดของผู้ใช้งาน

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/10/aura-markdown-new-doc-image-system-20260310-151317-9ufg0a.png)
  </Step>

  <Step>
    หลังจากที่มีการแก้ไขข้อมูลเรียบร้อยแล้ว ให้เลื่อนลงด้านล่างและคลิกปุ่ม `บันทึก`

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/10/aura-markdown-new-doc-image-system-20260310-151343-1h1pz6.png)

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/10/aura-markdown-new-doc-image-system-20260310-151847-1c8xik.png)
  </Step>
</Steps>

## จัดการข้อมูลส่วนบุคคล

สำหรับหน้า "จัดการข้อมูลส่วนบุคคล" ใช้สำหรับการเพิ่มข้อมูลที่อยู่ของผู้ใช้งานและข้อมูลการติดต่อส่วนบุคคล

<Steps>
  <Step>
    คลิกเลือกผู้ใช้งานที่ต้องการแก้ไข

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/10/aura-markdown-new-doc-image-system-20260310-152643-1wv3xv.png)
  </Step>

  <Step>
    เลือกหัวข้อ "จัดการข้อมูลส่วนบุคคล" คลิกปุ่ม `+ เพิ่มข้อมูลส่วนบุคคล` ระบบจะแสดงหน้ารายละเอียดของที่อยู่และข้อมูลการติดต่อ

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/10/aura-markdown-new-doc-image-system-20260310-152702-oe3fao.png)
  </Step>

  <Step>
    ระบบจะแสดงหน้ารายละเอียดของที่อยู่และข้อมูลการติดต่อในส่วนนี้สามารถแก้ไขหรือทำการเพิ่มข้อมูลในระบบได้

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/10/aura-markdown-new-doc-image-system-20260310-152726-lxydhu.png)
  </Step>

  <Step>
    หลังจากที่มีการแก้ไขข้อมูลเรียบร้อยแล้ว ให้เลื่อนลงด้านล่างและคลิกปุ่ม `บันทึก`

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/10/aura-markdown-new-doc-image-system-20260310-153415-1qrqcy.png)
  </Step>
</Steps>

## จัดการสิทธิ์

สำหรับหน้า "จัดการสิทธิ์" ใช้สำหรับการเพิ่มเมนูในการใช้งานต่างๆ ให้แสดงขึ้นมาในหน้าระบบของผู้ใช้งานและเพิ่มสิทธิ์ในการเป็นผู้ใช้งานหรือเป็นผู้ดูแลระบบ

<Steps>
  <Step>
    คลิกเลือกผู้ใช้งานที่ต้องการแก้ไข

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/10/aura-markdown-new-doc-image-system-20260310-152643-1wv3xv.png)
  </Step>

  <Step>
    เลือกหัวข้อ "จัดการสิทธิ์"

    <Callout>
      เมื่อกำหนดสิทธิ์การใช้งานเมนูใดๆให้เป็น OFF ทั้งหมด User และ Admin <u>เมนูดังกล่าวจะไม่ปรากฏในระบบ</u>
    </Callout>

    <Callout type="warn">
      หากมีการปิดสิทธิ์ใช้งานเมนู Portal (ตั้งค่าเป็น OFF) ทั้งสิทธิ์ User และ Admin <u>ระบบจะไม่อนุญาตให้ผู้ใช้งานเข้าสู่ระบบ</u>
    </Callout>

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/10/aura-markdown-new-doc-image-system-20260310-160142-1sd7ut.png)
  </Step>

  <Step>
    หากต้องการกำหนดสิทธิ์ให้เป็นผู้ใช้งานทั่วไปหรือเป็นผู้ดูแลระบบ สามารถดำเนินการสลับปุ่ม ที่แสดงในหน้า"จัดการสิทธิ์"ของผู้ใช้งานท่านนั้นๆ ตัวอย่างเช่น

    สำหรับผู้ใช้งานทั่วไป

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/10/aura-markdown-new-doc-image-system-20260310-163717-1xhxj2.png)

    สำหรับผู้ดูแลระบบ

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/10/aura-markdown-new-doc-image-system-20260310-163751-1mpa4o.png)
  </Step>
</Steps>

## จัดการสายบังคับบัญชา

สำหรับหน้า "จัดการสายบังคับบัญชา" ใช้สำหรับเพิ่มลำดับสายบังคับบัญชาให้แก่บุคลากร สามารถใช้กับระบบจองรถได้ในกรณีที่มีการตั้งค่า

<Steps>
  <Step>
    คลิกเลือกผู้ใช้งานที่ต้องการแก้ไข

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/11/aura-markdown-new-doc-image-system-20260311-091635-7v4uyy.png)
  </Step>

  <Step>
    เลือกหัวข้อ "จัดการสายบังคับบัญชา" จากนั้นคลิกปุ่ม `แก้ไข`

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/11/aura-markdown-new-doc-image-system-20260311-091655-1k4u2s.png)
  </Step>

  <Step>
    ระบบจะแสดงหน้า แก้ไขสายบังคับบัญชา จากนั้นระบุชื่อ-นามสกุลตามลำดับหลังจากดำเนินการเรียบร้อยและคลิกปุ่ม `บันทึก`

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/11/aura-markdown-new-doc-image-system-20260311-091713-1lb4vk.png)
  </Step>

  <Step>
    ระบบจะแสดงรายชื่อผู้ใช้งานที่ทำการเพิ่มเข้าระบบ หากต้องการลบผู้ใช้งานท่านนี้ออกสามารถคลิกที่ปุ่ม `กากบาท` ระบบจะขึ้นข้อความให้ยืนยันลบผู้บังคับบัญชา จากนั้นคลิกปุ่ม `OK` เพื่อยืนยันการลบ

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/11/aura-markdown-new-doc-image-system-20260311-091736-1td0t7.png)
  </Step>
</Steps>

## จัดการบัญชี

สำหรับหน้า "จัดการบัญชี" ใช้สำหรับจัดการกับบัญชีของผู้ใช้งาน เช่น การเปลี่ยนรหัส การปิดบัญชีของผู้ใช้และการตั้งค่าเปลี่ยนรหัสเมื่อมีการเข้าสู่ระบบครั้งแรก

![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/11/aura-markdown-new-doc-image-system-20260311-094816-thjbhg.png)

ส่วนประกอบภายในหน้า"จัดการบัญชี"

1. ปุ่ม `Reset Password`
1. ปุ่ม `การใช้งาน`
1. ปุ่ม `ตั้งค่าเปลี่ยนรหัส(เมื่อมีการ login ครั้งแรก)`

### ปุ่ม `Reset Password`

ใช้สำหรับ การตั้งรหัสผ่านใหม่ ในการเข้าใช้งานระบบ

<Steps>
  <Step>
    คลิกปุ่ม `Reset Password`

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/11/aura-markdown-new-doc-image-system-20260311-094853-knkk41.png)
  </Step>

  <Step>
    ระบุรหัสผ่านที่ต้องการใหม่ จากนั้นคลิกปุ่ม บันทึก

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/11/aura-markdown-new-doc-image-system-20260311-094927-jj1lyl.png)
  </Step>
</Steps>

### ปุ่ม `การใช้งาน`

ใช้สำหรับ เปิด/ปิด การใช้งานของผู้ใช้งานท่านนั้น

<Callout>
  หากปิดการใช้งานผู้ใช้งานท่านนั้นจะ  <u>ไม่สามารถเข้าสู่ระบบได้</u>
</Callout>

![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/11/aura-markdown-new-doc-image-system-20260311-094949-14c8u2.png)

หากมีการคลิกปุ่มปิดการใช้งานให้เป็น OFF ของผู้ใช้งานท่านนั้น ระบบจะขึ้นข้อความแจ้งเตือนสามารถคลิกยืนยันหรือยกเลิกในระบบได้

![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/11/aura-markdown-new-doc-image-system-20260311-095028-u8x8u1.png)

### ปุ่ม `ตั้งค่าเปลี่ยนรหัส`

ใช้สำหรับการตั้งรหัสผ่านเมื่อมีการเข้าใช้งานระบบครั้งแรก หากเปิดให้เป็น ON เมื่อผู้ใช้งานเข้าสู่ระบบครั้งแรกระบบจะให้เปลี่ยนรหัสผ่านใหม่ในการเข้าใช้งานระบบ

![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/11/aura-markdown-new-doc-image-system-20260311-095057-1lktrk.png)
