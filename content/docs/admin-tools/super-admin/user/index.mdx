## องค์ประกอบภายในหน้าเมนู

![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/05/aura-markdown-new-doc-image-system-20260305-142733-xjeeni.png)

ภายในหน้าเมนูประกอบด้วยส่วนต่าง ๆ ดังนี้

1. ช่องค้นหาข้อมูลผู้ใช้งาน
2. ส่วนแสดงรายการข้อมูลผู้ใช้งาน
3. ปุ่ม `นำเข้าไฟล์`
4. ปุ่ม `+ เพิ่ม`
