ใช้สำหรับค้นหาข้อมูลผู้ใช้งานภายในระบบ และจัดการข้อมูลของผู้ใช้เช่น เพิ่มข้อมูลผู้ใช้งานใหม่เข้าระบบ เป็นต้น

## วิธีเข้าสู่หน้าเมนู

<Steps>
  <Step>
    เข้าสู่เมนู **หน้าแรก (Portal)**
  </Step>

  <Step>
    คลิกเข้าสู่เมนูระบบ **Admin Tools**

    ![](https://r2-eoffice-docs.zire.dev/uploads/markdown/2026/03/04/aura-markdown-new-doc-image-system-20260304-151308-fl2rem.png)
  </Step>

  <Step>
    คลิกเลือกแท็บ **จัดการผู้ใช้งาน** ที่แถบเมนูด้านบน

    ![](https://r2-eoffice-docs.zire.dev/uploads/markdown/2026/03/04/aura-markdown-new-doc-image-system-20260304-135441-1xgmyp.png)
  </Step>
</Steps>

***

## องค์ประกอบภายในหน้าเมนู

![](https://r2-eoffice-docs.zire.dev/uploads/markdown/2026/03/05/aura-markdown-new-doc-image-system-20260305-142733-xjeeni.png)

ภายในหน้าเมนูประกอบด้วยส่วนต่าง ๆ ดังนี้

1. ช่องค้นหาข้อมูลผู้ใช้งาน
2. ส่วนแสดงรายการข้อมูลผู้ใช้งาน
3. ปุ่ม `นำเข้าไฟล์`
4. ปุ่ม `+ เพิ่ม`
