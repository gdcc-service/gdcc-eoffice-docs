ใช้สำหรับเพิ่มข้อมูลโครงสร้างภายในหน่วยงานที่ยังไม่ปรากฏในระบบ เช่น ตำแหน่ง ประเภทบุคลากร และระดับของบุคลากร เพื่อให้ข้อมูลมีความครบถ้วนและสอดคล้องกับโครงสร้างของหน่วยงาน

## วิธีเข้าสู่หน้าเมนู

<Steps>
  <Step>
    เข้าสู่เมนู **หน้าแรก (Portal)**
  </Step>

  <Step>
    คลิกเข้าสู่เมนูระบบ **Admin Tools**

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/04/aura-markdown-new-doc-image-system-20260304-151308-fl2rem.png)
  </Step>

  <Step>
    คลิกเลือกแท็บด์ **ข้อมูลหลักองค์กร** ที่แถบเมนูด้านบน

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/03/04/aura-markdown-new-doc-image-system-20260304-135900-5ur8wf.png)
  </Step>
</Steps>
