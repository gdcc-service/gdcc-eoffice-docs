## วิธีแก้ไขไอคอนเมนู

<Steps>
  <Step>
    เข้าสู่หน้า [แท็บจัดการระบบ](/docs/admin-tools/super-admin/listsys)
  </Step>

  <Step>
    คลิกที่ปุ่ม ไอคอนรูปเฟือง ที่อยู่ด้านขวาของเมนูที่ต้องการแก้ไขไอคอนและรูปภาพ
  </Step>

  <Step>
    ระบบจะแสดงหน้าจอสำหรับการตั้งค่าการแสดงผลของเมนูต่างๆ ภายในระบบ โดยสามารถทำการแก้ไขไอคอนและรูปภาพละสีของเมนูได้ตามต้องการ
  </Step>

  <Step>
    หลังจากทำการแก้ไขไอคอนและรูปภาพเรียบร้อยแล้ว ให้คลิกปุ่ม `บันทึก` เพื่อบันทึกการเปลี่ยนแปลงไอคอนและรูปภาพของเมนูต่างๆ ภายในระบบ
  </Step>

  <Step>
    ระบบจะแสดงไอคอนและรูปภาพของเมนูต่างๆ ภายในระบบตามที่ได้ทำการแก้ไขไว้
  </Step>
</Steps>
