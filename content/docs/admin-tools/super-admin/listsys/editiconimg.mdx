## วิธีแก้ไขไอคอนเมนู

<Steps>
  <Step>
    เข้าสู่หน้า [แท็บด์จัดการระบบ](/docs/admin-tools/super-admin/listsys)
  </Step>

  <Step>
    คลิกที่ปุ่ม ไอคอนรูปเฟือง ที่อยู่ด้านขวาของเมนูที่ต้องการแก้ไขไอคอนและรูปภาพ

    ![](/media/9beaf039-24af-41b0-baa9-0e46dab27e9a.png)
  </Step>

  <Step>
    ระบบจะแสดงหน้าจอสำหรับการตั้งค่าการแสดงผลของเมนูต่างๆ ภายในระบบ โดยสามารถทำการแก้ไขไอคอนและรูปภาพละสีของเมนูได้ตามต้องการ

    ![](/media/b487f5b1-8293-4ba7-939a-0efad72dba00.png)
  </Step>

  <Step>
    หลังจากทำการแก้ไขไอคอนและรูปภาพเรียบร้อยแล้ว ให้คลิกปุ่ม `บันทึก` เพื่อบันทึกการเปลี่ยนแปลงไอคอนและรูปภาพของเมนูต่างๆ ภายในระบบ

    <Callout type="info">
      การแก้ไขไอคอนและรูปภาพผู้ใช้งานทั้งหมดจะเห็นการเปลี่ยนแปลงไอคอนและรูปภาพของเมนูต่างๆ ภายในระบบตามที่ได้ทำการแก้ไขไว้
    </Callout>

    ![](/media/a7c72609-c376-49ea-96c6-1e83feba4312.png)
  </Step>

  <Step>
    ระบบจะแสดงไอคอนและรูปภาพของเมนูต่างๆ ภายในระบบตามที่ได้ทำการแก้ไขไว้

    ![](/media/ba0fc3bf-fe37-4f67-b843-84d4458f3062.png)
  </Step>
</Steps>
