---

## วิธีแก้ไขไอคอนเมนู

<Steps>
  <Step>
    เข้าสู่หน้า [แท็บด์จัดการระบบ](/docs/admin-tools/super-admin/listsys)
  </Step>

  <Step>
    คลิกที่ปุ่ม ไอคอนรูปเฟือง ที่อยู่ด้านขวาของเมนูที่ต้องการแก้ไขไอคอนและรูปภาพ

    ![](https://r2-eoffice-docs.zire.dev/uploads/markdown/2026/03/12/aura-markdown-new-doc-image-system-20260312-110840-qfulte.png)
  </Step>

  <Step>
    ระบบจะแสดงหน้าจอสำหรับการตั้งค่าการแสดงผลของเมนูต่างๆ ภายในระบบ โดยสามารถทำการแก้ไขไอคอนและรูปภาพละสีของเมนูได้ตามต้องการ

    ![](https://r2-eoffice-docs.zire.dev/uploads/markdown/2026/03/12/aura-markdown-new-doc-image-system-20260312-110857-qop271.png)
  </Step>

  <Step>
    หลังจากทำการแก้ไขไอคอนและรูปภาพเรียบร้อยแล้ว ให้คลิกปุ่ม `บันทึก` เพื่อบันทึกการเปลี่ยนแปลงไอคอนและรูปภาพของเมนูต่างๆ ภายในระบบ

    <Callout type="info">
      การแก้ไขไอคอนและรูปภาพผู้ใช้งานทั้งหมดจะเห็นการเปลี่ยนแปลงไอคอนและรูปภาพของเมนูต่างๆ ภายในระบบตามที่ได้ทำการแก้ไขไว้
    </Callout>

    ![](https://r2-eoffice-docs.zire.dev/uploads/markdown/2026/03/12/aura-markdown-new-doc-image-system-20260312-110918-1r2q3l.png)
  </Step>

  <Step>
    ระบบจะแสดงไอคอนและรูปภาพของเมนูต่างๆ ภายในระบบตามที่ได้ทำการแก้ไขไว้

    ![](https://r2-eoffice-docs.zire.dev/uploads/markdown/2026/03/12/aura-markdown-new-doc-image-system-20260312-110940-1mdgab.png)
  </Step>
</Steps>
