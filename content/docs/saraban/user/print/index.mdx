## องค์ประกอบภายในหน้าเมนู

![](/media/d6f6b507-a28d-4e7f-94ad-6dda2cecc851.png)

ภายในหน้าเมนูประกอบด้วยส่วนต่าง ๆ ดังนี้

1. ช่องสำหรับเลือกประเภททะเบียนและรูปแบบรายงาน 
2. ช่องสำหรับระบุเงื่อนไขช่วงวันที่สร้าง
3. ช่องสำหรับระบุเงื่อนไขเพิ่มเติม เช่น เลขรับ, เลขที่เอกสาร, เรื่อง, จาก, เรียน, หรือเล่มทะเบียนปลายทาง
4. ช่องแสดงรายการเอกสารที่ค้นหา
