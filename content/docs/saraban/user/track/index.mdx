## องค์ประกอบภายในหน้าเมนู

ภายในหน้าเมนูประกอบด้วยส่วนต่าง ๆ ดังนี้

![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/07/07/aura-markdown-new-doc-image-system-20260707-101207-18wmf1.png)

1. ช่องสำหรับระบุข้อมูล เช่น ที่ เลขรับเอกสารภายนอก (เล่มต้นเรื่อง) เรื่อง จาก เรียบ
2. ช่องสำหรับเลือกช่วงวันที่ เช่น จากวันที่ - ถึงวันที่
3. ปุ่ม `ค้นหา`
4. ช่องแสดงรายละเอียดของเอกสารที่ค้นหาได้
