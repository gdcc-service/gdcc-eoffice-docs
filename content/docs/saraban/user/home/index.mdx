## องค์ประกอบภายในหน้าเมนู

![](https://r2-eoffice-docs.zire.dev/uploads/markdown/2026/03/13/aura-markdown-new-doc-image-system-20260313-095053-1ihycg.png)

ภายในหน้าเมนูประกอบด้วยส่วนต่าง ๆ ดังนี้

1. ปีปฏิทินและปีงบประมาณ
2. ประเภทแฟ้มทะเบียน
3. ช่องแสดงสิทธิ์ในแฟ้มทะเบียน
4. ช่องแสดงรายการเอกกสารในแฟ้มทะเบียน
