## การกำหนดตัวช่วยพิมพ์

    <Steps>

      <Step>
        เข้าสู่หน้า [แท็บด์กำหนดตัวช่วยพิมพ์](/docs/saraban/user/type-helper-manager) ในเมนูระบบ e-Saraban
      </Step>

      <Step>
        จากนั้นคลิกเลือก `กำหนดตัวช่วยพิมพ์`

        ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/07/06/aura-markdown-new-doc-image-system-20260706-111130-11glja.png)
      </Step>

      <Step>
        ดำเนินการพิมพ์ข้อความ คำเกษียน/ความเห็น/ข้อสั่งการ ในช่องดังกล่าว และคลิกปุ่ม `+ เพิ่ม`

        ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/07/06/aura-markdown-new-doc-image-system-20260706-111146-o3krb9.png)
      </Step>

      <Step>
        หลังจากเพิ่มตัวช่วยพิมพ์เรียบร้อยแล้ว คลิกปุ่ม `บันทึก`

        ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/07/06/aura-markdown-new-doc-image-system-20260706-111200-1dtb26.png)
      </Step>

    </Steps>

### วิธีใช้งานตัวช่วยพิมพ์

ในขั้นตอนการเสนอพิจารณาเอกสาร ผ่านเมนู "ระบบสารบรรณ" ระบบจะแสดงข้อความตัวช่วยพิมพ์ที่ได้เพิ่มไว้ในขั้นตอนการกำหนดตัวช่วยพิมพ์ขึ้นมาให้เลือก สามารถคลิกเลือกข้อความที่ต้องการได้ทันที โดยไม่ต้องพิมพ์ข้อความเอง

![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/07/06/aura-markdown-new-doc-image-system-20260706-112154-jgfi0z.png)
