## วิธีเข้าสู่หน้าเมนู 

<Steps>

  <Step>
    เข้าสู่เมนู <b>หน้าแรก (Portal)</b>
  </Step>

  <Step>
    คลิกเข้าสู่เมนู <b>หน้าแรก (e-Saraban)</b>

    
  </Step>

  <Step>
    เปลี่ยนสิทธิ์การใช้งานจาก User เป็น Admin ที่แถบเมนูด้านขวาบน

    
  </Step>

  <Step>
    เลือกแท็บด์ <b>จัดการ dConnect</b> จากแถบเมนูด้านบน

    
  </Step>
</Steps>

## องค์ประกอบภายในหน้าเมนู


ภายในหน้าเมนูประกอบด้วยส่วนต่าง ๆ ดังนี้

1. ปุ่มสำหรับซิงค์ข้อมูลกล่องรับ–ส่งจาก dConnect
2. ช่องแสดงชื่อกล่องรับ–ส่งที่เชื่อมต่อกับ dConnect
