## วิธีเข้าสู่หน้าเมนู 

<Steps>
  <Step>
    เข้าสู่เมนู <b>หน้าแรก (e-Saraban)</b>
  </Step>

  <Step>
    เปลี่ยนสิทธิ์การใช้งานจาก User เป็น Admin ที่แถบเมนูด้านขวาบน
  </Step>

  <Step>
    เลือกแท็บด์ <b>โครงสร้างสารบรรณองค์กร</b> จากแถบเมนูด้านบน
  </Step>
</Steps>

***

## องค์ประกอบภายในหน้าเมนู

ภายในหน้าเมนูประกอบด้วยส่วนต่าง ๆ ดังนี้
