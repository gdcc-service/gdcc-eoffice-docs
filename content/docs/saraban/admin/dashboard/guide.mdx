title: "Dashboard"
---

แท็บด์ Dashboard ใช้สำหรับแสดงข้อมูลสถิติของระบบสารบรรณ เช่น ปริมาณของหนังสือรอรับ/รอส่งทั้งหมดของทุกแฟ้มทะเบียน

## วิธีเข้าสูหน้า Dashboard

    <Steps>
      <Step>
        เข้าสู่หน้า [แท็บด์ Dashboard](/docs/saraban/admin/dashboard) ในเมนูระบบ e-Saraban
      </Step>

      <Step>
        ระบบจะแสดงข้อมูลสถิติของหนังสือในระบบระบบสารบรรณทั้งหมดขึ้นมา
      </Step>
    </Steps>
