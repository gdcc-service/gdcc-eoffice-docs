## การสร้างกลุ่ม

ใช้สำหรับสร้างโฟลเดอร์สำนักงาน งาน กอง กลุ่ม/ฝ่าย ก่อนที่จะสร้างแฟ้มทะเบียน

### วิธีการสร้างกลุ่ม

<Steps>
  <Step>
    คลิกที่ปุ่ม `สร้างกลุ่ม`

    ![](/media/bb38af08-3064-434d-bdcb-5267e0939323.png)
  </Step>

  <Step>
    ระบบจะแสดงหน้าต่างโดยให้ระบุชื่อกลุ่ม เช่น สารบรรณกลาง เป็นต้น แล้วคลิก `ตกลง` หรือคลิกยกเลิกหากไม่ต้องการสร้างกลุ่ม

    ![](/media/8104193c-2b38-4a04-80ff-676a94363a42.png)
  </Step>

  <Step>
    เมื่อสร้างกลุ่มสำเร็จระบบจะแสดงกลุ่มที่สร้างขึ้นมา ประกอบไปด้วย ชื่อกลุ่ม วันที่สร้าง และประเภท

    ![](/media/b8301360-717f-4ff2-9d3e-09b7f0c8756d.png)
  </Step>
</Steps>

## จัดการลำดับ

ใช้จัดลำดับกลุ่ม/แฟ้ม ตามที่ต้องการ

### วิธีการจัดลำดับ

<Steps>
  <Step>
    คลิกที่ปุ่ม `จัดการลำดับ`

    ![](/media/0aa98fc5-e749-4f72-8ebe-7c5af85d1945.png)
  </Step>

  <Step>
    คลิกที่กลุ่ม/แฟ้มที่ต้องการจัดลำดับแล้วเลื่อนขึ้นหรือเลื่อนลงเพื่อขยับตำแหน่งตามที่ต้องการ เมื่อดำเนินการจัดตำแหน่งเรียบร้อยแล้ว คลิก `บันทึก`

    ![](/media/c37ab254-18e1-46d0-9c77-8d0e642df83b.png)
  </Step>

  <Step>
    ระบบจะแสดงกลุ่ม/แฟ้มที่จัดลำดับเรียบร้อยแล้ว

    ![](/media/bbbae479-ebb9-40b7-aa9c-0ad4e3a1172f.png)
  </Step>
</Steps>

## การสร้างแฟ้มทะเบียน

ใช้สำหรับสร้างแฟ้มทะเบียนในกลุ่มที่ได้มีการสร้างไว้แล้ว เพื่อใช้ในการรับและส่งหนังสือในระบบ

### วิธีการสร้างแฟ้มทะเบียน

<Steps>
  <Step>
    เข้าที่กลุ่มงานที่ต้องการสร้างแฟ้มทะเบียน
  </Step>

  <Step>
    คลิกที่ปุ่ม `สร้างแฟ้ม` เพื่อทำการสร้างแฟ้มทะเบียน
  </Step>

  <Step>
    ระบุชื่อส่วนงาน สำนักงาน กอง กลุ่ม/ฝ่าย เช่น สารบรรณกลาง \[หนังสือรับ] ดังรูป
  </Step>

  <Step>
    จากนั้นเลือกประเภทของแฟ้ม

    ระบุเลข running number ตัวอย่าง ก %r1%/%y4% รูปแบบเลขคือ ก 1/2568

    | เลขรัน |
    | :---- |
    | %r1% คือ การรันเลข 1 ตำแหน่ง เช่น 1 2 3 4 5 เป็นต้น |
    | %r2% คือ การรันเลข 2 ตำแหน่ง เช่น 01 02 03 04 05 เป็นต้น |
    | %r4% คือ การรันเลข 4 ตำแหน่ง เช่น 0001 0002 0003 เป็นต้น |

    | เลขปีปฏิทิน |
    | :---- |
    | %y2% คือ เลขปี พ.ศ. 68 |
    | %y4% คือ เลขปี พ.ศ. 2568 |

    | เลขปีงบประมาณ |
    | :---- |
    | %by4% |
  </Step>

  <Step>
    กำหนดเลขเริ่มต้นของการรันเลข โดยระบบจะเริ่มรันเลขต่อเนื่องจากเลขที่ระบุ

    <Callout type="info" title="หมายเหตุ">
      กรณีไม่ระบุเลขจะรันเริ่มต้นที่ 1
    </Callout>
  </Step>
</Steps>

หนังสือรับ

* รับได้ทั้งภายในและภายนอก
* รับได้เฉพาะภายใน
* รับได้เฉพาะภายนอก (ใช้เลขทะเบียนใหม่) คือ ไม่ใช้เลขทะเบียนต้นทางลงรับ เช่น ต้นเรื่องลงรับภายนอกได้เลขทะเบียน 1 หากส่งต่อไปให้ปลายทางลงรับแล้วจะได้เลขทะเบียน 5 (เลขรัน ต่อจากเลขทะเบียนล่าสุดของแฟ้มรับปลายทาง)
* รับได้เฉพาะภายนอก (ใช้เลขทะเบียนเดิม) คือ ใช้เลขทะเบียนต้นทางที่ลงรับ เช่น ต้นเรื่องลงรับภายนอกได้เลขทะเบียน 1 หากส่งต่อไปให้ปลายทางลงรับแล้วจะได้เลขทะเบียน 1 ทุกแฟ้มทะเบียนตลอดเส้นทางเดินเอกสาร

หนังสือส่ง

* ส่งภายในและภายนอก
* ส่งภายใน
* ส่งภายนอก

หนังสือภายนอก

* ไม่รองรับแฟ้มไฟล์

หนังสืออื่นๆ (ประกาศ/คำสั่ง)

* ไม่สามารถส่งต่อภายในได้ หากต้องการส่งต่อต้องสร้างเป็นประเภทหนังสือส่งภายใน

## รายละเอียดในแฟ้มทะเบียน

### การแก้ไขชื่อแฟ้ม

<Callout type="info" title="หมายเหตุ">
      หากมีการแก้ไขชื่อแฟ้มทะเบียน ประวัติการออกเลขหรือรับหนังสือในอดีตทั้งหมดของแฟ้มทะเบียนนี้จะถูกแก้ไขเป็นชื่อที่ระบุใหม่ ซึ่งอาจจะทำให้ยากต่อการค้นหาหนังสือ
</Callout>

<Steps>
  <Step>
    เลือกแฟ้มที่ต้องการแก้ไขชื่อแฟ้มทะเบียน
  </Step>

  <Step>
    คลิกในช่องเพื่อแก้ไขชื่อแฟ้มทะเบียน
  </Step>

  <Step>
    จากนั้นคลิกปุ่ม `บันทึก` เพื่อบันทึกการแก้ไขชื่อแฟ้มทะเบียน
  </Step>
</Steps>

### การตั้งค่า format เลข Running

<Callout type="info" title="หมายเหตุ">
      สามารถแก้ไขได้รูปแบบเลขที่หนังสือแล้วคลิกบันทึก หากออกเลขหรือลงรับหลังจากแก้ไขจะเป็นรูปแบบใหม่ตามที่แก้ไข แต่จะไม่ส่งผลกับหนังสือที่มีการออกเลขไปก่อนหน้านี้
</Callout>

<Steps>
  <Step>
    เลือกแฟ้มที่ต้องการตั้งค่า
  </Step>

  <Step>
    คลิกในช่องตั้งค่า format เลข Running
  </Step>

  <Step>
    จากนั้นคลิกปุ่ม `บันทึก` เพื่อบันทึกค่าที่มีการแก้ไข
  </Step>
</Steps>

### การตั้งค่าเลขเริ่มต้น

<Callout type="info" title="หมายเหตุ">
      สามารถแก้ไขค่าเลขเริ่มต้นให้มากกว่าเลขปัจจุบันได้ แต่จะไม่สามารถย้อนเลขเริ่มต้นให้น้อยกว่าเลขปัจจุบันได้
</Callout>

<Steps>
  <Step>
    เลือกแฟ้มที่ต้องการตั้งค่าเลขเริ่มต้น
  </Step>

  <Step>
    คลิกในช่องตั้งค่าเลขเริ่มต้น
  </Step>

  <Step>
    จากนั้นคลิกปุ่ม `บันทึก` เพื่อบันทึกค่าเลขเริ่มต้น
  </Step>
</Steps>

### ช่องแสดงสถานะ

<Callout type="info" title="หมายเหตุ">
      หากเลือกสถานะไม่ใช้งานจะไม่แสดงแฟ้มทะเบียนนี้ในหน้าระบบของผู้ใช้งานและไม่แสดงแฟ้มทะเบียนนี้ให้เลือกในหน้าส่งต่อ
</Callout>

<Steps>
  <Step>
    คลิกที่ช่องสถานะ
  </Step>

  <Step>
    ระบบจะแสดงสถานะ ใช้งาน และ ไม่ใช้งาน จากนั้นให้เลือกสถานะที่ต้องการ
  </Step>

  <Step>
    หลังจากที่เลือกแล้วคลิกปุ่ม `บันทึก` เพื่อบันทึกสถานะ
  </Step>
</Steps>

### รูปแบบจัดเก็บเอกสาร (Archive)

ใช้สำหรับการจัดเก็บเอกสารในแฟ้มทะเบียน โดยจะไม่สามารถดำเนินการใดๆ กับเอกสารได้



### เปิดให้ส่งผ่าน dConnect

ใช้สำหรับเปิดสิทธิ์ให้แฟ้มทะเบียนให้มีการ “ส่งผ่าน dConnect” ในหน้ารายละเอียดเอกสารของทางฝั่งผู้ใช้งาน

<Callout type="info" title="หมายเหตุ">
      สามารถเปิดสิทธิ์ได้ทั้งแฟ้มทะเบียนหนังสือส่งและแฟ้มทะเบียนหนังสือรับ
</Callout>



### เปิดให้ส่งผ่าน Email

ใช้สำหรับเปิดให้ส่งผ่าน E-mail ในหน้ารายละเอียดเอกสารของทางฝั่งผู้ใช้งาน

<Callout type="info" title="หมายเหตุ">
     ผู้ใช้งานจะต้องมีสิทธิ์ในอีเมลด้วยถึงจะมองเห็นปุ่มส่งอีเมล
</Callout>



### ข้อความประทับตราลงรับ

ใช้เพิ่มข้อความสำหรับประทับตราลงรับหนังสือของแฟ้มทะเบียนส่วนงาน เมื่อมีการลงรับทางฝั่งผู้ใช้งาน

<Callout type="info" title="หมายเหตุ">
     ผู้ใช้งานจะต้องมีสิทธิ์ในอีเมลด้วยถึงจะมองเห็นปุ่มส่งอีเมล
</Callout>



### ตั้งค่า Format เลข Running เป็นรูปแบบพื้นฐาน

ใช้เพิ่มรูปแบบเลขที่หนังสือของส่วนงาน โดยเพิ่มรูปแบบเลขที่หนังสือในช่อง คลิกเพิ่มแล้วเลื่อน
ลงไปด้านล่างสุดเพื่อคลิกบันทึก เมื่อเจ้าหน้าที่ทำการออกเลขจะสามารถเลือกรูปแบบเลขที่หนังสือจากหน้า
ระบบที่แอดมินเพิ่มได้

### กลุ่มองค์กร

ใช้สำหรับกำหนดกลุ่มของแฟ้มทะเบียนหนังสือรับ เพื่อจัดกลุ่มแฟ้มทะเบียนปลายทางในหน้าส่งต่อหนังสือ โดยแฟ้มทะเบียนที่กำหนดชื่อกลุ่มเดียวกันจะถูกแสดงรวมอยู่ในกลุ่มเดียวกัน

<Steps>
  <Step>
    เลือกแฟ้มที่ต้องการตั้งค่ากลุ่มองค์กร
  </Step>

  <Step>
    ระบุชื่อกลุ่มองค์กรแล้วคลิก Enter
  </Step>

  <Step>
    จากนั้นคลิกปุ่ม `บันทึก` เพื่อบันทึกกลุ่มองค์กร
  </Step>
</Steps>

### จัดการข้อความอัตโนมัติ

ใช้เพิ่มข้อความเริ่มต้นให้แสดงผลในช่องจากและเรียนถึง หลังจากนั้นคลิกบันทึก

<Callout type="info" title="หมายเหตุ">
     แฟ้มทะเบียนหนังสือส่งจะแสดงในช่องจาก ส่วนแฟ้มทะเบียนหนังสือรับจะแสดงในช่องเรียนถึง
</Callout>



### จัดการผู้พิจารณาเอกสาร

ใช้สำหรับกำหนดรายชื่อผู้มีสิทธิ์พิจารณาเอกสารในแฟ้มทะเบียน เช่น ผู้บริหาร หัวหน้างาน หรือผู้อำนวยการ เป็นต้น เมื่อเพิ่มรายชื่อและคลิก "บันทึก" แล้ว รายชื่อดังกล่าวจะแสดงเป็นตัวเลือกสำหรับการเสนอพิจารณาหนังสือในระบบสารบรรณ



### จัดการเพิ่มสิทธิ์การใช้งาน

ใช้เพิ่มชื่อเจ้าหน้าที่ผู้ที่มีสิทธิ์ในแฟ้มทะเบียนของส่วนงาน โดยสามารถกำหนดสิทธิ์ที่เกี่ยวข้องกับแฟ้มทะเบียนได้ เช่น สิทธิ์ในการออกเลข สิทธิ์ในการลงรับหนังสือ สิทธิ์ในการส่งต่อหนังสือ 



แบ่งสิทธิ์ออกเป็น 3 แบบ

1. สิทธิ์สร้างและส่ง ใช้ในประเภทหนังสือส่งมีสิทธิ์ออกเลขและส่งเอกสาร

2. สิทธิ์รับและส่ง ใช้ในประเภทหนังสือรับมีสิทธิ์ในการลงรับและส่งเอกสาร

3. สิทธิ์อ่านอย่างเดียว มีสิทธิ์ดูและดาวน์โหลดเอกสาร

## การจัดการสิทธิ์

ใช้สำหรับการแก้ไขชื่อกลุ่มและให้สิทธิ์แอดมินประจำกอง กลุ่ม/ฝ่าย นั้นๆ โดยมีขั้นตอนดังนี้

<Steps>
  <Step>
    เลือกกลุ่มงานที่ต้องการจัดการสิทธิ์
  </Step>

  <Step>
    คลิกที่ปุ่ม `จัดการสิทธิ์` เพื่อทำการจัดการสิทธิ์ ระบบจะแสดงหน้าจักการใช้งาน



    สามารถคลิกที่ช่อง แก้ไขชื่อ เพื่อแก้ไขชื่อกลุ่มงานได้ และสามารถคลิกที่ช่อง สถานะ เพื่อเลือกสถานะการใช้งานของกลุ่มงานได้ โดยมีสถานะให้เลือกคือ ใช้งาน และ ไม่ใช้งาน

    <Callout type="info" title="หมายเหตุ">
      กรณีเปลี่ยนสถานะเป็นไม่ใช้งานจะทำให้ในหน้าส่งต่อเอกสารไม่แสดงกลุ่มนี้รวมถึงแฟ้มทะเบียนที่อยู่ภายใต้กลุ่มดังกล่าวทั้งหมด
    </Callout>



    หากต้องการ เพิ่มสิทธิ์ Admin ประจำกลุ่ม สามารถพิมพ์ค้นหาชื่อเจ้าหน้าที่ท่านนั้น จากนั้นทำการคลิกที่ชื่อเจ้าหน้าที่ท่านนั้นเพื่อเพิ่มสิทธิ์ Admin ได้
  </Step>

  <Step>
    หลังจากที่ดำเนินการแล้ว คลิกปุ่ม `บันทึก` เพื่อบันทึกการเพิ่มสิทธิ์ Admin ประจำกลุ่มงาน
  </Step>
</Steps> 

## วิธีการย้ายแฟ้มทะเบียน

<Steps>
  <Step>
    คลิกเข้าที่กลุ่มงานที่ต้องการย้ายแฟ้มทะเบียน
  </Step>

  <Step>
    ติ๊กที่ด้านหน้าของแฟ้มทะเบียนที่ต้องการย้าย จากนั้นคลิกที่ปุ่ม `ย้ายแฟ้ม` เพื่อทำการย้ายแฟ้มทะเบียนไปยังกลุ่มงานอื่น
  </Step>

  <Step>
    ระบบจะแสดงหน้าป๊อปอัพ กรุณาเลือกโฟลเดอร์ที่ต้องการ ให้คลิก `ตกลง` เพื่อย้ายแฟ้มทะเบียน
  </Step>

  <Step>
