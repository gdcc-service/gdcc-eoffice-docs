## องค์ประกอบภายในหน้าเมนู

![](/media/4abcc32c-5e93-4c6e-b101-44dedc512bb2.png)

ภายในหน้าเมนูประกอบด้วยส่วนต่าง ๆ ดังนี้

1. ช่องสำหรับค้นหาชื่อกลุ่มงานหรือแฟ้มทะเบียน
2. ช่องแสดงรายการกลุ่มงานหรือแฟ้มทะเบียนที่มีอยู่
3. ปุ่มสำหรับจัดการลำดับ
4. ปุ่มสำหรับสร้างกลุ่ม
