## องค์ประกอบภายในหน้าเมนู

![](/media/f1f827c5-2b46-4dd7-bfbd-ad5f15ace21d.png)

ภายในหน้าเมนูประกอบด้วยส่วนต่าง ๆ ดังนี้

1. หน้าสำหรับออกรายงานเล่มทะเบียน
2. หน้าสำหรับออกรายงานสถิติเอกสารลับ
3. ช่องค้นหาเอกสารลับและออกรายงาน
