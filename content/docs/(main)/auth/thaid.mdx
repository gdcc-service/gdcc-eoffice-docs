## FAQ

### ปัญหาเข้าสู่ระบบไม่ได้

<Accordions>
  <Accordion title="ไม่พบข้อมูลผู้ใช้ในระบบ กรุณาติดต่อผู้ดูแลระบบ">
    ```markdown
    สาเหตุอาจเกิดจาก:
    1. ไม่พบชื่อ–นามสกุลของผู้ใช้ในระบบ
    2. ชื่อ–นามสกุลของผู้ใช้สะกดผิดหรือมีอักขระอื่นๆ ทำให้ไม่ตรงกับข้อมูลใน ThaID
    3. บัญชีถูกระงับเนื่องจากไม่มีการเข้าใช้งาน ครั้งแรกใน 60 วัน
    4. เข้าลิงก์ URL ผิดหน่วยงาน

    ```

    ```markdown
    วิธีแก้ไขเบื้องต้น:
    1. เข้าสู่ระบบด้วย ชื่อบัญชีผู้ใช้งาน(Username/Password) แทนการใช้ ThaID
    2. แจ้งให้เจ้าหน้าที่ที่มีสิทธิ์ในเมนู Admin Tools ตรวจสอบความถูกต้องของชื่อ–นามสกุล
    3. ตรวจสอบว่า URL ที่ใช้เข้าใช้งานถูกต้องหรือไม่

    ```

  </Accordion>
  <Accordion title="กรุณาปิดหน้านี้ หมดเวลาแสดง QRcode">
    ```markdown
    สาเหตุอาจเกิดจาก:
    1. ผู้ใช้ไม่ได้สแกน QR Code ThaID เพื่อเข้าสู่ระบบให้สำเร็จภายในเวลาที่กำหนด

    ```

    ```markdown
    วิธีแก้ไขเบื้องต้น:
    1. กลับไปที่หน้า Login แล้วคลิกปุ่ม "เข้าสู่ระบบด้วย ThaID" ใหม่อีกครั้ง

    ```

  </Accordion>
  <Accordion title="curl failed: Could not resolve host: imauth.bora.dopa.go.th">
      ```markdown
    สาเหตุอาจเกิดจาก:
    1. ไม่สามารถเชื่อมต่อไปยังเซิร์ฟเวอร์ ThaID ได้ในขณะนี้

    ```

    ```markdown
    วิธีแก้ไขเบื้องต้น:
    1. เข้าสู่ระบบด้วย ชื่อบัญชีผู้ใช้งาน(Username/Password) แทนการใช้ ThaID
    2. ลองเปลี่ยนอุปกรณ์ที่ใช้เข้าสู่ระบบเป็นเครื่องอื่น
    3. รอซักครู่แล้วลองใหม่อีกครั้ง

    ```

  </Accordion>
  <Accordion title='{"status":"error","message":"Session expired."}'>
      ```markdown
    สาเหตุอาจเกิดจาก:
    1. Browser ที่ใช้แสดง QR Code ThaID และ Browser ที่ใช้หลังจากสแกนสำเร็จ เป็นคนละตัวกัน ทำให้ Session ไม่ตรงกัน

    ```

    ```markdown
    วิธีแก้ไขเบื้องต้น:
    1. เข้าสู่ระบบด้วย ชื่อบัญชีผู้ใช้งาน(Username/Password) แทนการใช้ ThaID
    2. ลองเปลี่ยนอุปกรณ์ที่ใช้เข้าสู่ระบบเป็นเครื่องอื่น
    3. เปลี่ยนไปใช้ Browser อื่น แล้วลองใหม่อีกครั้ง

    ```

  </Accordion>
    <Accordion title="Invalid code. No code provided. (Error code : 400)">
      ```markdown
    สาเหตุอาจเกิดจาก:
    1. ผู้ใช้กดปุ่ม ไม่ยินยอม ในแอพ ThaID

    ```

    ```markdown
    วิธีแก้ไขเบื้องต้น:
    1. เมื่อสแกน QR Code ThaID แล้วให้กดปุ่ม ยินยอม
    2. เข้าสู่ระบบด้วย ชื่อบัญชีผู้ใช้งาน(Username/Password) แทนการใช้ ThaID

    ```

  </Accordion>
