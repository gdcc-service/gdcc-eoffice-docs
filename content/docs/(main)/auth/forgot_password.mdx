---
title: ลืมรหัสผ่าน
---

ใช้สำหรับรีเซ็ตรหัสผ่านใหม่ในกรณีลืมรหัสผ่านหรือเพื่อกำหนดรหัสผ่านสำหรับเข้าใช้งานระบบครั้งแรก

## การรีเซ็ตรหัสผ่านใหม่

<Steps>
  <Step>
    หลังจากที่เข้าลิงก์ URL ของหน่วยงานของท่านแล้ว ระบบจะแสดงหน้าสำหรับเข้าสู่ระบบให้คลิกที่ปุ่ม `ลืมรหัสผ่าน?`

    ![](https://r2-eoffice-docs.zire.dev/uploads/markdown/2026/02/25/aura-markdown-new-doc-image-system-20260225-103102-1mmdl0.png)
  </Step>

  <Step>
    ระบบจะแสดงหน้าลืมรหัสผ่าน ให้ระบุอีเมลและรหัสภาพ Captcha ในส่วนของช่อง Captcha ให้ใส่รหัสภาพ Captcha ให้ตรงตามที่ปรากฏ โดยพิมพ์ติดกันไม่ต้องเว้นช่องว่าง จากนั้นคลิกที่ปุ่ม `ส่ง Email`

    ![](https://r2-eoffice-docs.zire.dev/uploads/markdown/2026/02/25/aura-markdown-new-doc-image-system-20260225-103126-e6qbdb.png)
  </Step>

  <Step>
    หากดำเนินการถูกต้องระบบจะทำการส่งลิงก์ในการกำหนดรหัสผ่านใหม่ไปยังอีเมลของผู้ใช้งาน

    ![](https://r2-eoffice-docs.zire.dev/uploads/markdown/2026/02/25/aura-markdown-new-doc-image-system-20260225-103148-1c64p5.png)
  </Step>

  <Step>
    ผู้ใช้งานทำการตรวจสอบอีเมลหัวข้อ การเปลี่ยนรหัสผ่าน สามารถคลิกที่ "ลิงก์ URL" หรือ `กดที่นี่เพื่อเปลี่ยนรหัสผ่าน`

    ![](https://r2-eoffice-docs.zire.dev/uploads/markdown/2026/02/25/aura-markdown-new-doc-image-system-20260225-103226-1199os.png)
  </Step>

  <Step>
    หลังจากนั้นระบบจะแสดงหน้าการกำหนดรหัสผ่านใหม่

    <Callout type="warn" title="รหัสผ่านต้องประกอบด้วย">
      ตัวอักษรอังกฤษพิมพ์ใหญ่,
      ตัวอักษรอังกฤษพิมพ์เล็ก,
      ตัวเลข,
      ตัวอักขระพิเศษ #?!@$%^&\*-.+,
      ความยาวไม่น้อยกว่า 8 ตัวอักษร
    </Callout>

    ![](https://r2-eoffice-docs.zire.dev/uploads/markdown/2026/02/25/aura-markdown-new-doc-image-system-20260225-103337-na9l0p.png)

    หากดำเนินการถูกต้อง ในแต่ละหัวข้อจะแสดงเป็นสีเขียว และให้คลิกปุ่ม `ยืนยัน` จากนั้นดำเนินการ [เข้าสู่ระบบด้วย Username](/docs/auth/username)
  </Step>
</Steps>

***

    ```markdown

    1. ไม่มีผู้ใช้งานที่ใช้อีเมลนี้ในระบบ
    2. อีเมลที่เคยลงไว้ในระบบสะกดผิดหรือมีอักขระอื่นๆ
    3. เข้าลิงก์ URL ผิดหน่วยงาน

    ```

    ```markdown
    วิธีแก้ไขเบื้องต้น:

    2. เข้าสู่ระบบด้วย ThaID
    3. ตรวจสอบว่า URL ที่ใช้เข้าใช้งานถูกต้องหรือไม่

    ```


    ```markdown

    2. ให้ตรวจสอบในอีเมลจดหมายขยะ(Spam) ว่ามีหัวข้อ(การเปลี่ยนรหัสผ่าน)แสดงในถังขยะหรือไม่
    ```
