    ```markdown
    สาเหตุอาจเกิดจาก:
    1. ชื่อบัญชีผู้ใช้งานหรือรหัสผ่านไม่ถูกต้อง

    3. เข้าลิงก์ URL ผิดหน่วยงาน

    ```

    ```markdown
    วิธีแก้ไขเบื้องต้น:
    1. ติดต่อเจ้าหน้าที่ที่มีสิทธิ์ในเมนู Admin Tools ให้ทำการตรวจสอบหรือแก้ไขชื่อบัญชีผู้ใช้งานใหม่
    2. เข้าสู่ระบบด้วย ThaID
    3. ตรวจสอบว่า URL ที่ใช้เข้าใช้งานถูกต้องหรือไม่

    ```
