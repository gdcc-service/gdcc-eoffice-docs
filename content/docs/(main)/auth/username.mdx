## การเข้าสู่ระบบด้วย Username

<Steps>
  <Step>
    เข้าลิงก์ URL หน่วยงานของท่าน จากนั้นระบบจะแสดงหน้าสำหรับเข้าสู่ระบบ

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/25/aura-markdown-new-doc-image-system-20260225-084525-gtvap9.png)
  </Step>

  <Step>
    กรอกชื่อบัญชีผู้ใช้งานและรหัสผ่าน
    โดยในช่อง "ชื่อบัญชีผู้ใช้งาน" ให้ระบุ “ชื่อจริง” ตามด้วยจุด (.) และตามด้วย “อักษรสามตัวแรกของนามสกุล” เป็นภาษาอังกฤษ\
    ตัวอย่างเช่น **นายสมชาย ใจดี** จะใช้ชื่อบัญชีผู้ใช้งานคือ **somchai.jai**

    <Callout type="warn">
      หากมีการเข้าสู่ระบบล้มเหลวติดกันมากกว่า 10 ครั้ง บัญชีของท่านจะถูกระงับ
    </Callout>

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/25/aura-markdown-new-doc-image-system-20260225-084900-1fr1vx.png)
  </Step>

  <Step>
    หลังจากนั้นคลิกปุ่ม เข้าสู่ระบบ เรียบร้อยแล้ว ระบบจะพาไปยังหน้าเมนูระบบ [หน้าหลัก (Portal)](/docs/portal)

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/25/aura-markdown-new-doc-image-system-20260225-085224-16i0je.png)
  </Step>
</Steps>

## FAQ

### ปัญหาต่างๆ

<Accordions>
  <Accordion title="ชื่อบัญชีผู้ใช้งานหรือรหัสผ่านไม่ถูกต้อง(ERR_E001)">
    ```markdown
    สาเหตุอาจเกิดจาก:
    1. ชื่อบัญชีผู้ใช้งานหรือรหัสผ่านไม่ถูกต้อง
    2. ชื่อบัญชีผู้ใช้งานที่เคยลงไว้ในระบบสะกดผิดหรือมีอักขระอื่นๆ
    3. เข้าลิงก์ URL ผิดหน่วยงาน

    ```

    ```markdown
    วิธีแก้ไขเบื้องต้น:
    1. ติดต่อเจ้าหน้าที่ที่มีสิทธิ์ในเมนู Admin Tools ให้ทำการตรวจสอบหรือแก้ไขชื่อบัญชีผู้ใช้งานใหม่
    2. เข้าสู่ระบบด้วย ThaID
    3. ตรวจสอบว่า URL ที่ใช้เข้าใช้งานถูกต้องหรือไม่

    ```
  </Accordion>

  <Accordion title="ชื่อบัญชีผู้ใช้งานหรือรหัสผ่านไม่ถูกต้อง(ERR_E002)">
    ```markdown
    สาเหตุอาจเกิดจาก:
    1. รหัสผ่านไม่ถูกต้อง

    ```

    ```markdown
    วิธีแก้ไขเบื้องต้น:
    1. กดปุ่ม ลืมรหัสผ่าน เพื่อรีเซ็ตรหัสผ่านใหม่
    2. เข้าสู่ระบบด้วย ThaID
    3. ติดต่อเจ้าหน้าที่ที่มีสิทธิ์ในเมนู Admin Tools เพื่อรีเซ็ตรหัสผ่านใหม่

    ```
  </Accordion>

  <Accordion title="บัญชีของท่านถูกระงับการใช้งาน กรุณาติดต่อผู้ดูแลระบบ(ERR_E003)">
    ```markdown
    สาเหตุอาจเกิดจาก:
    1. บัญชีถูกปิดการใช้งาน
    2. มีการเข้าสู่ระบบล้มเหลวติดกันมากกว่า 10 ครั้ง

    ```

    ```markdown
    วิธีแก้ไขเบื้องต้น:
    1. ติดต่อแอดมินผู้ดูแลหน่วยงาน
    2. ติดต่อเจ้าหน้าที่ที่มีสิทธิ์ในเมนู Admin Tools เพื่อเปิดการใช้งานบัญชี

    ```
  </Accordion>

  <Accordion title="ท่านไม่มีสิทธิ์เข้าถึงระบบ Portal">
    ```markdown
    สาเหตุอาจเกิดจาก:
    1. ไม่มีสิทธิ์ใดๆในเมนูระบบ Portal
    2. หลังจากบัญชีถูกปิดและเปิดการใช้งานใหม่อีกครั้ง แล้วยังไม่มีการเปิดสิทธิ์ในเมนูระบบ Portal กลับคืน

    ```

    ```markdown
    วิธีแก้ไขเบื้องต้น:
    1. ติดต่อเจ้าหน้าที่ที่มีสิทธิ์ในเมนู Admin Tools เพื่อเพิ่มสิทธิ์ในเมนูระบบ Portal

    ```
  </Accordion>
</Accordions>
