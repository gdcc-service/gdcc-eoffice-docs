## แนะนำส่วนประกอบต่างๆ

ใช้สำหรับการสร้างรลิงก์เพื่อให้เข้าถึงเว็บไชต์ต่างๆ ในหน้าหลักของระบบส่วนประกอบของหน้าลิงก์  มีดังนี้

![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/26/aura-markdown-new-doc-image-system-20260226-091726-7wlo83.png)

1\. ปุ่ม “+ เพิ่มLink“ <br />
2\. ปุ่มเปลี่ยนชื่อ <br />
3\. การแสดงหัวข้อLink

## การสร้างลิงก์

<Steps>
  <Step>
    คลิกที่ปุ่ม “+ เพิ่มLink“

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/26/aura-markdown-new-doc-image-system-20260226-092944-vdz0j3.png)
  </Step>

  <Step>
    จากนั้นให้กำหนดชื่อของลิงก์ และระบุ URL Website ที่ต้องการ จากนั้นคลิกปุ่ม “บันทึก“

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/26/aura-markdown-new-doc-image-system-20260226-093306-cb7po2.png)
  </Step>

  <Step>
    หากดำนเนินการเรียบร้อยแล้ว URL Website ดังกล่าวจะแสดงในระบบ

    ![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/26/aura-markdown-new-doc-image-system-20260226-093529-qybwyi.png)
  </Step>
</Steps>
