---
title: วิธีการใช้งาน GDCC e-Office Mobile App
---

แอปพลิเคชันที่ใช้สำหรับการเข้าสู่ระบบโดบการสแกน QR Code เพื่อเข้าสู่ระบบผ่าน GDCC e-Office Mobile App

## วิธีการดาวน์โหลดแอปพลิเคชัน GDCC e-Office Mobile App

<Steps>
  <Step>
    เข้าสู่หน้า [แท็บด์ GDCC e-Office Mobile App](/docs/portal/user/mobile-sync) 
  </Step>

  <Step>
    เลือกหัวข้อ <b>GDCC e-Office Mobile App</b>

    ![](/media/28648eb8-df2d-41ec-bb45-5e3f18127016.png)
  </Step>

  <Step>
    ทำการสแกน QR Code ที่หน้าระบบเพื่อดาวน์โหลดแอปพลิเคชัน GDCC e-Office Mobile App ลงบนสมาร์ทโฟนของท่าน หรือพิมพ์ค้นหาผ่าน App Store หรือ Google Play Store ได้ 

    ![](/media/0ba85dc3-e626-4110-b875-18928b853dad.png)
  </Step>

  <Step>
    เมื่อติดตั้งแอปพลิเคชันเรียบร้อยแล้ว จะแสดงแอปพลิเคชัน GDCC e-Office Mobile App บนสมาร์ทโฟนของท่าน

    ![](/media/da6cf1e7-2014-4abc-8af3-a070aa53a022.png)
  </Step>
</Steps>

***

## วิธีลงทะเบียน GDCC e-Office (สำหรับผู้ใช้ใหม่)

<Steps>
  <Step>
    เปิดแอปพลิเคชัน GDCC e-Office Mobile App บนสมาร์ทโฟนของท่าน
  </Step>

  <Step>
    จากนั้นคลิกที่ "ลงทะเบียนด้วย ThaID"

    ![](/media/cbae70b0-f422-42e9-8824-a21b3263366e.png)
  </Step>

  <Step>
    แอปพลิเคชันจะให้ยินยอมนโยบาลของแอป และจะเข้าสู่หน้ายืนยันข้อมูลผ่านแอปพลิเคชัน ThaID 

    ![](/media/2c41fd8d-df53-4146-aee8-583c19ac2438.png)
  </Step>

  <Step>
    เมื่อทำการยืนยันข้อมูลผ่านแอปพลิเคชัน ThaID แล้ว จะเข้าสู่หน้าการใช้งานของแอปพลิเคชัน GDCC e-Office Mobile App ให้ทำการติ๊กที่ช่องเพื่อยืนยันข้อมูลถูกต้องอีกครั้ง

    ![](/media/1e4547cc-00b5-4105-b2f3-c79e12cd9ffe.png)
  </Step>

  <Step>
    จากนั้นกรอกอีเมลของท่านลงในช่องและคลิก `ถัดไป` แอปพลิเคชันจะส่งรหัส OTP ที่ส่งไปยังอีเมลของท่านพร้อมแสดงหน้าสำหรับกรอกรหัส OTP ขึ้นมา

    ![](/media/d12f7fb6-8b9c-4ff5-bc7a-891c8f19349d.png)
  </Step>

  <Step>
    ตรวจสอบรหัส OTP ที่ส่งไปยังอีเมลของท่าน และนำรหัส OTP ที่ท่านได้รับมากรอกลงในช่องและคลิก `ถัดไป`

    ![](/media/7a8501e0-05c5-4e01-96f0-ef19271dfad2.png)
  </Step>

  <Step>
    แอปพลิเคชันจะให้ทำการระบุรหัสและยืนยันรหัสผ่านใหม่ ในการเข้าใช้งานแอปพลิเคชัน GDCC e-Office Mobile App

    ![](/media/7e973637-e608-4a9f-984e-1035460b86ec.png)
  </Step>

<Step>
    เมื่อทำการระบุรหัสและยืนยันรหัสผ่านใหม่แล้ว จะเข้าสู่หน้าแอปพลิเคชัน GDCC e-Office Mobile App และจะแสดงหน้าข้อมูลของผู้ใช้งานขึ้นมา

    ![](/media/e8cc46df-01c0-4654-b4cc-fdce58ad7eae.png)
  </Step>

</Steps>

## วิธีเข้าใช้งาน GDCC e-Office (สำหรับผู้ใช้งานที่มีบัญชี)

<Steps>
  <Step>
    เปิดแอปพลิเคชัน GDCC e-Office Mobile App บนสมาร์ทโฟนของท่าน
  </Step>

  <Step>
    จากนั้นคลิกที่ `เข้าสู่ระบบด้วย ThaID` ระบบจะสลับไปยังแอปพลิเคชัน ThaiD เพื่อให้กดยินยอมการเข้าใช้งาน เมื่อดำเนินการเรียบร้อย จะเข้าสู่หน้าแอปพลิเคชัน GDCC e-Office Mobile App และจะแสดงหน้าข้อมูลของผู้ใช้งานขึ้นมา

    ![](/media/a94b0c5a-5d12-4780-b43c-ee66630081e1.png)
  </Step>

</Steps>

## การใช้งาน GDCC e-Office Mobile App

GDCC e-Office Mobile App เป็นแอปพลิเคชันที่ใช้สำหรับการเข้าระบบโดยการสแกน QR Code ผ่านลิงก์หน้าเว็บไซต์ของหน่วยงานและยังสามารถรับการแจ้งเตือนข้อมูลในการทำงานจากเว็บ e-Office ผ่าน GDCC e-Office Mobile App

### การเข้าใช้งานระบบ e-Office ผ่านการสแกน QR Code ดัวยแอปพลิเคชัน GDCC e-Office Mobile App

<Steps>
  <Step>
    ทำการเปิดหน้าเว็บไซต์ e-Office ของหน่วยงานขึ้นมา  คลิกปุ่ม `เข้าสู่ระบบด้วย e-Office Mobile`

    ![](/media/c0c543a3-7008-4cf4-a8a4-fc6762fc0293.png)
  </Step>

  <Step>
    ระบบจะแสดงหน้าต่างสำหรับการสแกน QR Code

    ![](/media/e1d1cfa6-930f-4c42-9e47-591f924b6a87.png)
  </Step>

  <Step>
    จากนั้นให้ทำการเปิดแอปพลิเคชัน GDCC e-Office Mobile App ที่ได้มีการติดตั้งไว้บนสมาร์ทโฟนของท่าน คลิกปุ่ม `สแกน QR Code` ที่อยู่กลางหน้าจอบนสมาร์ทโฟนของท่าน

    ![](/media/980aa08e-f509-4ce8-9d8b-423703ccc671.png)
  </Step>

  <Step>
    นำสมาร์ทโฟนของท่านไปสแกน QR Code ที่แสดงอยู่ที่หน้าระบบเว็บไซต์ e-Office ของหน่วยงาน

    ![](/media/489c3b32-57f5-4cd3-a7c7-a3d769473803.png)
  </Step>

  <Step>
    เมื่อดำเนินการสแกนแล้ว จะเข้าสู่หน้าเมนูหลักสำหรับการใช้งาน

    ![](/media/8f9a0eb4-ff3a-4f22-ae24-79d684a44acf.png)
  </Step>

</Steps>

## เมนูการใช้งาน GDCC e-Office Mobile App

### หน้าหลักของแอปพลิเคชัน GDCC e-Office Mobile App จะแสดงเมนูตามตัวเลขดังนี้

![](/media/b83f50f0-054b-4337-a278-87971663e52f.png)

หมายเลข 1. หน้าหลัก จะแสดงข้อมูลของผู้ใช้งาน รูปโปรไฟล์ ชื่อผู้ใช้งาน อีเมล และรายละเอียดของหน่วยงาน

![](/media/807d3f06-bdf7-48ba-bf78-3b0c5f523030.png)

หมายเลข 2. ปุ่มสแกน QR Code จะใช้สำหรับการสแกน QR Code เข้าใช้งานระบบ e-Office ผ่านการ `เข้าสู่ระบบด้วย e-Office Mobile`

![](/media/ffa52f35-fd1a-4d22-afcb-524026be6f80.png)

หมายเลข 3. ปุ่มประวัติ จะใช้สำหรับการดูประวัติการเข้าสู่ระบบ e-Office

![](/media/d9dc49a2-b5d6-4fb6-9420-eec48ad81333.png)

หมายเลข 4. ปุ่มกระดิ่ง จะใช้สำหรับการดูการแจ้งเตือนการทำงานจากระบบ e-Office และข่าวสาร เช่น แจ้งเตือนเข้าสู่ระบบ แจ้งเตือนเอกสารรอตรวจสอบ แจ้งเตือนเอกสารรอดำเนินการ

![](/media/b3d64f72-ff8a-44ba-8cca-cd308d9e604e.png)

หมายเลข 5. ปุ่มสำหรับการตั้งค่า

![](/media/8ee46b5d-c969-4448-98cc-9dd7378dd835.png)

- การเปลี่ยนรหัสผ่าน ใช้ในการเปลี่ยนรหัสในการเข้าใช้งาน

![](/media/272e1e99-ec6d-4283-98b0-85199eb74585.png)

- การแก้ไขอีเมล จะเป็นการแก้ไขอีเมลของผู้ใช้งานในแอปพลิเคชัน GDCC e-Office Mobile App เท่านั้น

![](/media/4b63c1ee-7c62-41d0-a490-004eb9998a13.png)

- เกี่ยวกับแอป จะเป็นการแสดงข้อมูลเกี่ยวกับแอปพลิเคชัน

![](/media/f8c6dcf0-b59a-4407-a604-7c809cf8aadc.png)

- ข้อกำหนดและเงื่อนไข จะเป็นการแสดงข้อกำหนดและเงื่อนไขของแอปพลิเคชัน

![](/media/c53ad5f2-2306-4d2a-99fb-2d18ca9911ae.png)
