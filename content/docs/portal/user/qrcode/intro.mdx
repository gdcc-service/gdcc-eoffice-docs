## วิธีสร้างรูปภาพ QR Code

<Steps>
  <Step>
    คลิกที่ปุ่ม “+ สร้าง“

    ![](/media/6171ca3d-e3b6-44d4-be88-6f2ae9b8662f.png)
  </Step>

  <Step>
    นำลิงก์ที่ต้องสร้าง QR Code ใส่ในช่อง และ รายละเอียดให้ใส่ชื่อที่ต้องการ จากนั้นคลิกปุ่ม “บันทึก“

    ![](/media/4c1f75ab-bc81-4c29-a3ba-8cc1029b56c1.png)
  </Step>

  <Step>
    หลังจากที่สร้างเรียบร้อยแล้ว ลิงก์ดังกล่าวจะแสดงขั้นมาสามารถติ๊กในช่อง “checkbox“ ให้แสดงโลโก้ได้ และ สามารถ “บันทึกรูปภาพ“ ที่เป็น QR Code เพื่อนำไปใช้งานต่อได้

    ![](/media/f4cbe6f1-6e38-4b5e-8ca3-637d79172898.png)
  </Step>

  <Step>
    ลิงก์ที่มีการสร้างขั้นใหม่จะแสดงอยู่ด้านบนเสมอ
    ![](/media/ebc5bd2d-a951-40a2-b872-260562859cb0.png)
  </Step>
</Steps>

***

## วิธีดาวน์โหลด/ดู QR Code

<Steps>
  <Step>
    คลิกที่ปุ่มไอคอนรูป QR Code

    ![](/media/2a7e19f0-cd75-42b1-865b-299e21e71ac5.png)
  </Step>

  <Step>
    ระบบจะแสดง QR Code สามารถติ๊กในช่อง “checkbox“ ให้ไม่แสดงโลโก้ และ ดาวน์โหลดรูปที่เป็น QR Code เพื่อนำไปใช้งานต่อ

    ![](/media/145102d9-4436-4460-a76f-32692574a876.png)
  </Step>
</Steps>

***

## วิธีแก้ไข QR Code

<Steps>
  <Step>
    คลิกที่ปุ่ม “แก้ไข“

    ![](/media/9983e7e4-035f-4e5b-bba1-dba79e497c69.png)
  </Step>

  <Step>
    ระบบจะแสดงลิงก์และชื่อที่ต้องการแก้ไข หากแก้เรียบร้อยแล้วคลิกปุ่ม“บันทึก“

    ![](/media/65924dfa-6e06-472b-af11-ba7b427b86a3.png)
  </Step>
</Steps>

***

## วิธีลบ QR Code

เลือกลิงก์ที่ต้องการลบ จากนั้นคลิกที่ไอคอน จุด 3 จุด  คลิกเลือก “ลบ“ ระบบจะแสดงข้อความแจ้งเตือน คลิกปุ่ม OK เพื่อยืนยัน

![](/media/17463a59-2639-4e92-bee6-55260f88b85c.png)
