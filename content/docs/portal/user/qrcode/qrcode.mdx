# แนะนำส่วนประกอบต่างๆ 
ใช้สำหรับการนำลิงก์ต่างๆ ที่ใช้งานเป็นประจำมาสร้างให้อยู่ในรูปแบบของ QR Code เช่น คู่มือการใช้งานระบบ ส่วนประกอบของหน้า QR Code มีดังนี้

![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/24/aura-markdown-new-doc-image-system-20260224-142725-vfgjk7.png)

1\. ปุ่ม “+ สร้าง“\
2\. หน้าแสดงรายละเอียดของลิงก์\
3\. ปุ่มแสดงรูป QR Code\
4\. ปุ่มแก้ไขและลบ

---

## วิธีสร้างรูปภาพ QR Code

<Steps>
  <Step>
คลิกที่ปุ่ม “+ สร้าง“

![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/24/aura-markdown-new-doc-image-system-20260224-142940-1xhfgv.png)
  </Step>
  <Step>
นำลิงก์ที่ต้องสร้าง QR Code ใส่ในช่อง และ รายละเอียดให้ใส่ชื่อที่ต้องการ จากนั้นคลิกปุ่ม “บันทึก“

![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/24/aura-markdown-new-doc-image-system-20260224-143228-j1f5lw.png)
  </Step>
  <Step>
หลังจากที่สร้างเรียบร้อยแล้ว ลิงก์ดังกล่าวจะแสดงขั้นมาสามารถติ๊กในช่อง “checkbox“ ให้แสดงโลโก้ได้ และ สามารถ “บันทึกรูปภาพ“ ที่เป็น QR Code เพื่อนำไปใช้งานต่อได้

![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/24/aura-markdown-new-doc-image-system-20260224-143354-1llrcz.png)
  </Step>
  <Step>
ลิงก์ที่มีการสร้างขั้นใหม่จะแสดงอยู่ด้านบนเสมอ
![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/24/aura-markdown-new-doc-image-system-20260224-143633-1wuz7o.png)
  </Step>
</Steps>

## วิธีดาวน์โหลด/ดู QR Code

<Steps>
<Step>
คลิกที่ปุ่มไอคอนรูป QR Code

![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/24/aura-markdown-new-doc-image-system-20260224-143945-1d3blu.png)
</Step>
<Step>
ระบบจะแสดง QR Code สามารถติ๊กในช่อง “checkbox“ ให้ไม่แสดงโลโก้ และ ดาวน์โหลดรูปที่เป็น QR Code เพื่อนำไปใช้งานต่อ

![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/24/aura-markdown-new-doc-image-system-20260224-144140-1om87k.png)

</Steps>

## วิธีลบ QR Code

เลือกลิงก์ที่ต้องการลบ จากนั้นคลิกที่ไอคอน จุด 3 จุด  คลิกเลือก “ลบ“ ระบบจะแสดงข้อความแจ้งเตือน คลิกปุ่ม OK เพื่อยืนยัน

![](https://pub-32868b48992b43ebae1d6e46b84716f6.r2.dev/uploads/markdown/2026/02/24/aura-markdown-new-doc-image-system-20260224-144849-1q6yq2.png)
