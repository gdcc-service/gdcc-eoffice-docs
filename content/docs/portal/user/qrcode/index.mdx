## องค์ประกอบภายในหน้าเมนู

![](https://r2-eoffice-docs.zire.dev/uploads/markdown/2026/02/24/aura-markdown-new-doc-image-system-20260224-142725-vfgjk7.png)

ภายในหน้าเมนูประกอบด้วยส่วนต่าง ๆ ดังนี้

1. ปุ่ม `+ สร้าง`
2. หน้าแสดงรายละเอียดของลิงก์
3. ปุ่มแสดงรูป QR Code
4. ปุ่มแก้ไขและลบ
