## เมนูระบบย่อยสำหรับการใช้งานภายในหน่วยงาน

ใช้สำหรับการจัดการเกี่ยวกับการดำเนินงานภายในหน่วยงาน

![](/media/d04698b3-d15b-4aa6-8702-4b7deaa9cdb4.png)

1. Admin Tools (ตั้งค่าและแก้ไขข้อมูล) 
2. Draft (ระบบร่าง ทาน ตรวจเอกสาร) 
3. e-Saraban (ระบบสารบรรณ) 
4. In-tray (ระบบลงนามอิเล็กทรอนิกส์) 
5. eMeeting (ระบบการประชุม) 
6. News(แจ้งเวียน) 
7. Room Booking (ระบบจองห้องประชุม) 
8. Car Reservation (ระบบจองรถ) 
9. Archive (ระบบจัดเก็บเอกสาร)
