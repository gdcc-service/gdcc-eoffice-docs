## ขั้นตอนการจัดการข้อมูลส่วนบุคคล

ผู้ใช้ทุกท่านสามารถดำเนินการได้ด้วยตนเอง ตามขั้นตอนดังนี้

<Steps>
  <Step>เข้าสู่เมนู **หน้าแรก (Portal)**</Step>

  <Step>
    คลิกปุ่ม `จัดการข้อมูลส่วนบุคคล`

    <Callout>
      กรณีที่เมนูไม่แสดงเป็นเพราะมีการปิดไม่ให้ใช้งานฟังก์ชันเมนู `ข้อมูลส่วนบุคคลและรูปโปรไฟล์`
      [วิธีเปิดใช้งาน](/docs/portal/admin/extrafunc/intro#ข้อมูลส่วนบุคคลและรูปโปรไฟล์)
    </Callout>

    ![](/media/d51c1514-c18f-4cba-b628-88da2e1a8720.png)
  </Step>

  <Step>
    จะปรากฏหน้าต่าง จัดการข้อมูลส่วนบุคคล ให้ทำการแก้ไขข้อมูลที่ต้องการ
    หลังจากนั้นกดปุ่ม `ยืนยัน`
    ![](/media/e8282621-6d05-4c19-88c4-70774f52daa4.png)
  </Step>
</Steps>

## ส่วนประกอบของหน้าต่างจัดการข้อมูลส่วนบุคคล

ในหน้าต่างจัดการข้อมูลส่วนบุคคลแบ่งออกเป็น 3 ส่วนหลัก ดังนี้

### 1. ข้อมูลหลัก

ประกอบด้วยข้อมูลต่อไปนี้

* **รูปภาพโปรไฟล์**
  สามารถอัปโหลดได้ ขนาดไฟล์ไม่เกิน **2.5 MB**
* **ชื่อ - นามสกุล** *(แก้ไขได้เฉพาะผู้ดูแลระบบ)*
* **ตำแหน่ง** *(แก้ไขได้เฉพาะผู้ดูแลระบบ)*
* **หน่วยงานที่สังกัด** *(แก้ไขได้เฉพาะผู้ดูแลระบบ)*
* **Email หลัก** *(แก้ไขได้เฉพาะผู้ดูแลระบบ)*
* **เบอร์โทรศัพท์หลัก**

### 2. ข้อมูลการติดต่อเพิ่มเติม

ประกอบด้วยข้อมูลต่อไปนี้

* เบอร์โทรศัพท์ส่วนตัว
* เบอร์โทรศัพท์ส่วนตัว (สำรอง)
* Email ส่วนตัว
* LINE ID

### 3. ที่อยู่ปัจจุบัน

ประกอบด้วยข้อมูลต่อไปนี้

* ที่อยู่
* จังหวัด
* เขต/อำเภอ
* แขวง/ตำบล
* รหัสไปรษณีย์
